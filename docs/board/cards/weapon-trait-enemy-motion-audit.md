# 적 이동 영향 무기 특성 진단

## 목표

- 적의 위치·속도·진행 방향에 영향을 주는 무기 특성을 전수 식별한다.
- 각 특성의 입력부터 적 이동 반영까지 실제 데이터 흐름을 추적한다.
- 작동하지 않거나 비정상적으로 보이는 조건과 원인을 증거로 정리한다.

## 완료 조건

- 관련 특성별 구현 파일과 적용 단계를 설명한다.
- 적 타입·이동 컴포넌트에 따른 동작 차이를 구분한다.
- 구현 누락, 프레임 의존, 좌표 직접 변경 등 위험 요소를 우선순위로 정리한다.
- 이번 단계에서는 사용자 승인 없이 전투 로직을 변경하지 않는다.

## 조사 결과

- 관련 특성은 `plasma_gravity`와 `barrier_repulse` 2종이다.
- 두 구현 모두 적 위치를 즉시 옮기고 `MoveComponent.velocity`에 힘을 영구 가산한다. 감쇠·지속시간·외력 채널은 없다.
- Drone 편대와 Awl의 대기/조준 단계는 `MoveComponent`를 끄고 매 프레임 위치를 재작성하므로 효과가 사실상 덮인다.
- Striker·Bomb은 가산 속도가 계속 남다가 자체 상태 전환 시 일부 또는 전부 덮인다.
- Caster는 Y 위치를 고정하고 경계에서 X 속도를 재설정해 힘의 방향에 따라 일부만 보이거나 갑자기 취소된다.
- Barrier는 약 0.85초마다 재타격할 수 있어 `velocity += 140`이 반복 누적될 수 있다.
- Plasma는 거리 비례 최대 `velocity += 90`과 최대 4.5px 위치 이동을 동시에 적용한다.
- 두 특성의 이동 동작을 검증하는 전용 테스트는 없다.

## 구현 결과

- 공통 적 씬에 `MoveModifierComponent`를 추가했다.
- 외력 속도와 누적 오프셋은 감쇠되며 원래 AI 경로로 복귀한다.
- `MoveComponent`는 AI 이동량과 외력 오프셋 변화량을 합산한다.
- Drone과 Awl 편대 단계는 계산한 편대 위치에 외력 오프셋을 더한다.
- Striker와 Caster의 상태·경계 판정은 외력 오프셋을 제외한 AI 기준 좌표를 사용한다.
- 플라즈마 중력과 방벽 반발은 위치·AI 속도를 직접 변경하지 않고 `apply_impulse()`를 호출한다.
- 모든 적 파생 씬의 컴포넌트 상속, 일반 이동, Drone 편대, 두 무기 효과를 스모크 테스트로 검증한다.
- 플레이테스트 피드백에 따라 중력 수축의 흡인력을 `240`, 전용 흡인 반경을 피해 반경의 `1.6배`로 조정하고 거리 감쇠를 완화했다.
- 스트라이커 2체가 폭발 좌우에서 0.2초 안에 합계 12px 이상 수축하는 조건을 테스트에 추가했다.
- 방벽의 탄환 흡수용 Hurtbox와 적 본체 Hitbox가 겹칠 때 적이 체력 사망을 우회해 제거되는 경로를 제거했다.
- 적은 플레이어·방벽 접촉으로 제거되지 않으며, 플레이어는 모든 피격 후 기본 0.6초 무적을 얻는다.
- 공용 무적 상태 동안 플레이어와 적 기체 전체를 반투명하게 표시한다.
- 적 증강 `임사 체험`을 추가해 치명 피해를 HP 1로 가로채고 1초 무적 후 정상 사망 트리거를 발생시킨다.
- `충격 분산 골격`은 최종값 대체 대신 기본 무적시간에 1.0초를 가산해 총 1.6초를 제공한다.
- 플레이어 증강 선택 화면은 카드 Kind에 따라 시설 패널과 병기 배치 미리보기를 전환하며, 무기 Kind가 무기실을 잘못 하이라이트하지 않는다.
- 병기 미리보기는 신규 배치, 대상 병기 레벨 변화, 현재·추가 증강 정보를 표시한다.
- 전투 STATUS의 병기 설명은 고정 2줄 클리핑 영역으로 격리해 긴 설명이 640×360 월드 레이아웃을 팽창시키지 않는다.
