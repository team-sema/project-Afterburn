# 증강 분기점 UI 다듬기

## 목표

- 플레이어 증강과 적 증강의 진입 화면을 색상만으로도 즉시 구분할 수 있게 한다.
- 같은 브랜치에서 증강 화면의 자잘한 UI 문제를 함께 정리한다.

## 완료 조건

- 플레이어 강화 분기점은 기존 청색 테마를 유지한다.
- 적 강화 분기점은 적 증강 강조색을 반영한 적색 테마로 표시된다.
- 한 타입을 표시한 뒤 다른 타입을 열어도 이전 테마가 남지 않는다.
- 플레이어 증강 선택 패널의 제목과 함선 모듈이 360px 높이 안에서 잘리지 않는다.
- 좌우 HUD는 글자 크기와 안티앨리어싱 설정을 유지하면서 Nearest 필터와 정수 좌표로 표시된다.
