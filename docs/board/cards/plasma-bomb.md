# 플라즈마 폭탄 · WeaponSystem 튜닝 통합

## 목표

- 보조 캐넌과 역할이 겹치는 보조 플랙을 제거한다.
- 느리게 전방으로 투하된 폭탄이 시간차를 두고 폭발한다.
- 폭발 범위 안의 모든 적에게 큰 피해를 준다.
- 모든 무기의 전투 밸런스 설정을 각 WeaponSystem 루트로 통일한다.

## 완료 조건

- 보조 플랙의 무기 정의, 획득/강화 증강, 씬과 아이콘 참조가 남지 않는다.
- 플라즈마 폭탄이 기존 무기 레벨·피해·공속 배율을 적용받는다.
- 신관 시간 전에는 피해가 없고, 폭발 시 범위 안의 복수 적만 피해를 받는다.
- 메인 게임과 무기 테스트 씬에서 플라즈마 폭탄을 획득·장착할 수 있다.

## 설정 위치

- 모든 무기의 공격 간격, 기본 피해, 탄속과 고유 전투 수치는 각 `player_ship/weapons/*_weapon_system.tscn` 루트에서 조정한다.
- 투사체 씬은 충돌 형태와 연출만 소유하며, 전투 수치는 WeaponSystem이 생성 직전에 주입한다.
- `damage_radius_margin`은 보이는 `blast_radius` 바깥으로 피해 판정만 확장하며 기본값은 `0`이다.

## 구현

- 보조 플랙의 모든 등록·리소스·아이콘을 플라즈마 폭탄으로 교체했다.
- 플라즈마 폭탄은 WeaponSystem의 투하 속도, 신관 시간, 피해, 시각 반경과 판정 마진을 주입받는다.
- 기존 무기의 공격 간격과 투사체 전투 수치도 각 WeaponSystem 루트로 이전했다.
