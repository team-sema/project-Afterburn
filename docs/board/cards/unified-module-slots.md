# 범용 모듈 슬롯 통합

시설별 슬롯을 제거하고 모든 시설 효과 모듈이 공유하는 범용 슬롯 풀로 통합한다. 기존 무기실·동력로·엔진·선체·레이더·실드 분류와 아이콘은 모듈 tag로 유지한다.

## 목표

- 시작 5칸·최대 15칸의 5×3 육각 벌집 범용 슬롯
- 선체 시설 타일은 제거하고 모듈 tag와 기존 시설 아이콘은 슬롯 내부에 유지
- 만석 시 tag와 관계없이 임의 슬롯 교체
- 오퍼 1회를 소비하는 범용 슬롯 +1 확장
- 미래 tag 시너지를 위한 조회 API 제공
