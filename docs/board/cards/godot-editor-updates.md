# Godot 에디터 리소스 동기화

## 목표

- 에디터에서 갱신된 월드, 함선 시설 UI, 플라즈마 무기 리소스를 저장소에 반영한다.
- 명시값이 생략된 리소스도 런타임 기본값과 기존 연결을 유지한다.

## 완료 조건

- [x] 중앙 플레이필드 SubViewport와 HUD 표기가 모두 `240×360`으로 일치한다.
- [x] 월드에 인스턴스된 `ShipPanel`이 원본 씬의 최소 높이와 클리핑 설정을 유지한다.
- [x] 플라즈마 획득·레벨 증강은 기본 가중치 `1.0`, 시작 레벨 `1`과 무기 연결을 유지한다.
- [x] 관련 스모크 테스트와 프로젝트 파싱이 통과한다.
