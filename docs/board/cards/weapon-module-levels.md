# 무기 모듈 레벨 개편

무기 자체의 범용 Lv.1~3 성장을 제거하고, 각 무기 특성 모듈이 반복 획득으로 Lv.I~III 성장하도록 전환한다.

## 목표

- `WEAPON_LEVEL` 오퍼와 무기 자체 레벨·배율 제거
- `WEAPON_TRAIT`를 모듈 Lv.I~III 성장 카드로 운영
- 범용 피해·공격 속도 성장은 무기실 시설 모듈의 책임으로 분리
- 교체 시 해당 무기의 모듈 레벨 삭제 규칙 유지

## AC

- [x] 무기 획득 후 자체 레벨 없이 기본 수치로만 작동
- [x] 동일 특성 카드는 최대 Lv.III까지 등장하고 각 레벨이 효과를 강화
- [x] 최대 레벨 특성 카드는 오퍼 후보에서 제외
- [x] STATUS·증강 미리보기에 모듈 현재/다음 레벨 표시
- [x] 기존 무기 레벨 카드가 Gameplay 풀에서 제거됨
- [x] 관련 스모크·파싱 테스트 통과
