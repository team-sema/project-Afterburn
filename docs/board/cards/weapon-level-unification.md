# 무기 레벨 단일화

## 목표

- 슬롯 레벨과 무기 레벨의 이중 성장 체계를 제거한다.
- 슬롯은 장착 위치와 해금 상태만 보유한다.
- 모든 주·보조무기는 무기 ID별 Lv.1~3 성장과 동일한 배율 규칙을 사용한다.

## 완료 조건

- 주무기 강화는 현재 장착 무기 레벨을 올린다.
- 보조 강화는 선택한 슬롯에 장착된 무기 레벨을 올린다.
- 주무기 교체와 보조무기 소진·재획득 후에도 무기 레벨이 유지된다.
- HUD와 선택 UI에 슬롯 레벨이 표시되지 않는다.
- 관련 스모크 테스트와 프로젝트 파싱이 통과한다.

## 구현

- `WeaponSlotState`에서 슬롯 레벨과 슬롯 배율을 제거했다.
- 주·보조무기 모두 `PlayerWeaponLoadout`의 무기 ID별 레벨만 사용한다.
- 강화 오그먼트, 슬롯 선택 UI, 무장 HUD와 관련 리소스를 단일 무기 레벨 기준으로 갱신했다.
- 잔탄 없는 궤도 방벽 아이콘도 다른 보조무기와 같은 높이로 정렬했다.
- 적 편대별 생성·튜닝을 `EnemySpawnPattern` Resource로 분리해 Generator의 전용 분기를 제거했다.
