# 제출 가이드 문서 모듈 슬롯 반영

## 목표

`docs/submission/03-game-guide.md`의 플레이 방법 설명을 현재 구현(함선 모듈 슬롯)에 맞춘다. 심사자가 문서와 실제 화면이 다르다고 느끼지 않게 한다.

## 배경

플레이어 강화가 "무한 누적 오그먼트"에서 "함선 부위 슬롯에 장착하는 모듈"로 바뀌었다(`docs/design/systems/augment-module-slots.md`). 기존 가이드는 누적 모델로 설명하고 있었고, 선체·실드 분리와 실드 게이트도 빠져 있었다.

## AC

- [x] 핵심 루프가 모듈 장착·슬롯 확장·교체를 포함한다
- [x] 6부위와 슬롯 1→3칸 규칙을 설명한다
- [x] 슬롯이 찼을 때 교체·취소 흐름을 설명한다
- [x] 무기 강화 모듈이 장착 중에만 유효하다는 점을 적는다
- [x] 선체·실드 HUD와 실드 게이트(1 이상이면 그 피격 전부 흡수)를 설명한다
- [x] 종료 조건 표기를 HP → 선체로 교체한다
- [x] 오퍼 중 조작(마우스·방향키·Tab·Enter)을 조작 표에 반영한다
