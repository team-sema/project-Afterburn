# 보조 캐넌 옵션 드론 개편

## 목표
- 유도 캐넌을 플레이어 좌우에 붙는 전통적인 슈팅 게임식 옵션/부가 드론 무기로 개편한다.
- 각 드론은 플레이어를 따라다니며 전방으로 보조탄을 발사한다.
- 모듈 증강으로 보조 기체 수를 늘릴 수 있게 한다.

## 확정 규칙
- 기본 드론은 좌우 1기씩 총 2기다.
- 드론은 플레이어의 좌우 대칭 목표점을 살짝 느린 속도로 쫓아가며 전방으로 동시에 발사한다.
- 플레이어 본체 중심과 멀어질수록 추종 속도가 소폭 증가해 좌우 드론의 간격이 역동적으로 변한다.
- `aux_heavy_barrel` 호환 ID의 특성을 편대 증설 프레임으로 개편해 드론을 2기 추가한다.

- [x] 횡이동 반대편 드론이 본체와 더 멀어진 만큼 이동 방향 쪽 드론보다 빠르게 이동한다.
- [x] 보조탄은 유도하지 않고 전방으로 발사된다.
