# 이동 중 샷건 탄환 비표시 분석

## 현상

- 플레이어가 움직이면서 샷건을 발사하면 펠릿이 보이지 않는다.

## 조사 범위

- 샷건 발사 위치와 펠릿 초기 속도
- 플레이어 이동과 투사체 씬 트리 소유 관계
- 펠릿의 가시성, 수명, 화면 밖 제거 조건

## 완료 조건

- 정지 발사와 이동 발사의 차이를 재현한다.
- 펠릿이 생성되지 않는지, 즉시 제거되는지, 화면상으로만 보이지 않는지 구분한다.
- 원인 코드 경로와 근거를 기록한다.

## 분석 결과

- 펠릿은 정상 생성되지만 발사 위치가 월드 원점에서 280px 이상 떨어지면 첫 프레임에 제거된다.
- `player_shotgun_pellet.gd`의 `_ready()`는 `_last_pos`에 기본 위치 `(0, 0)`을 저장한다.
- `SpawnerComponent.spawn()`은 `add_child()`로 `_ready()`를 실행한 뒤에야 실제 발사 위치를 지정한다.
- 따라서 첫 `_process()`가 원점부터 발사 위치까지의 거리를 비행 거리로 잘못 더한다.
- 런타임 진단값: `(80, 216)` 생성은 거리 `230.339`로 유지, `(400, 216)` 생성은 거리 `454.594`로 즉시 제거.

## 구현

- 펠릿의 거리 누적과 최대 거리 종료 조건을 제거했다.
- 기본 사거리는 탄환 수명으로 대체했고 샷건 씬은 `base_pellet_lifetime = 0.75초`로 조정했다.
- 초크·단축 총열의 내부 `range_mult`를 `lifetime_mult`로 바꿨다.
- 플레이어에게 보이는 특성 설명의 “사거리” 표현은 유지했다.
- 원점에서 먼 생성 위치와 큰 위치 변화가 수명을 소모하지 않는 회귀 테스트를 추가했다.
- 서브픽셀에서 코어가 흐려지는 현상을 완화하도록 공유 탄환 SVG를 쓰는 네 탄환의 코어 X 스케일을 `0.25`로 맞췄다.
- 코어 몸통 폭은 약 1px이 되며 기존 Y 스케일·글로우·충돌 크기는 유지했다.
