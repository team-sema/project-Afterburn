# Threat 엘리트 · 보스 진행 루프

## 목표

Threat가 상승할 때마다 엘리트 적과의 전투를 만들고, 엘리트 처치 보상으로 적 증강을 선택한다. 일정 횟수의 Threat 진행 후에는 보스 전투를 삽입해 런의 중간 목표와 난이도 전환점을 만든다.

## 현재 결정된 방향

- 60초 타이머 완료가 엘리트 전투의 트리거이며, 처치가 Threat 상승 조건이다.
- 엘리트가 처치되었을 때 적 증강 3지선다를 연다.
- Threat가 N회 진행되면 보스가 등장한다. 예시 값은 10이며, 실제 값은 밸런싱 시 결정한다.
- 기존 일반 Encounter, Threat 기반 풀, 적 증강 레지스트리와 충돌하지 않도록 전투 상태를 분리한다.

## 완료 조건

- [x] 60초 경과 → 엘리트 등장 → 처치 및 Threat 상승 → 적 증강 선택의 전체 순서와 상태 전이가 확정된다.
- [ ] 보스 주기·등장 조건·엘리트/일반 스폰과의 우선순위가 확정된다.
- [ ] 엘리트와 보스의 데이터/씬/보상/실패 처리 경계가 정의된다.
- [ ] HUD·경고·증강 선택의 플레이어 피드백이 정의된다.
- [ ] 자동 테스트와 플레이테스트에 필요한 관측 항목 및 밸런싱 지표가 정해진다.
