# 무기 테스트장 증강·지속 스폰

## 목표

- 선택한 무기에 속한 특성 증강을 테스트장에서 직접 적용·초기화한다.
- 적 유형별 지속 스폰을 켜고 끄며 스폰 간격을 조절한다.
- 테스트장 밖의 게임 진행 상태와 생성 로직에는 영향을 주지 않는다.

## 완료 조건

- 장착 슬롯을 바꾸면 해당 무기의 특성 목록과 활성 상태가 표시된다.
- 특성 버튼으로 효과를 켜고 끌 수 있고, 선택 무기의 모든 특성을 초기화할 수 있다.
- 각 적 유형을 지속 스폰 대상으로 독립 선택할 수 있다.
- 설정한 간격마다 선택된 적 유형이 지정 배치 수만큼 생성되고, 모드를 끄면 즉시 중단된다.
- 클러스터 증강의 자탄은 트리 진입 전에 퓨즈가 설정되어 Timer 오류 없이 생성된다.
- 클러스터 자탄은 본체 진행 방향을 따르지 않고 폭발 지점에서 방사형으로 퍼진다.
- 잔류 필드는 실제 효과 반경에 맞는 반투명 플라즈마 장으로 표시된다.
- 발사 후 플라즈마 무기를 교체·해제해도 자탄과 잔류 필드는 발사 당시 피해 배율로 정상 동작한다.
- Lab 좌우 패널은 640×360 기준 화면을 벗어나지 않고 긴 적·무기·특성 목록은 패널 안에서 스크롤된다.
- 기존 수동 스폰, 무기 선택, 레벨 조절, 대상 정리가 계속 동작한다.
- 테스트장 스모크 테스트와 Godot 프로젝트 파싱 검사를 통과한다.
