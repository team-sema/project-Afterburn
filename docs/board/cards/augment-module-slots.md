# 증강 모듈 슬롯

## 목표

- 시설 효과 증강을 함선 부위 슬롯에 장착한다.
- 부위 효과는 시설 정의가 담당한다 (스탯 모듈 이중 경로 없음).
- 무기 획득·레벨·특성은 시설 슬롯을 쓰지 않는다.
