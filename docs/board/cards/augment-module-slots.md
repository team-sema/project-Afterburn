# 증강 모듈 슬롯

## 목표

- 스탯·시설 효과 증강을 함선 부위 슬롯에 장착한다.
- 무기 획득·레벨·특성은 시설 슬롯을 쓰지 않는다.
- 각 부위는 빈 슬롯 1개로 시작, 최대 3개까지 확장.
