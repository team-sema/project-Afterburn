# 증강 모듈 슬롯

## 목표

- 플레이어 증강을 함선 부위별 슬롯에 장착하는 모듈 시스템으로 전환한다.
- 각 함선 부위는 빈 슬롯 1개로 시작하고 최대 3개까지 확장할 수 있다.
- 증강 선택 화면에서 카드의 대상 부위를 함선 UI에 즉시 하이라이트한다.

## 완료 조건

- 플레이어 오퍼는 상단에 증강 3개, 하단에 함선 부위 UI를 함께 표시한다.
- 증강 선택 시 대상 부위의 빈 슬롯에 모듈을 장착한다.
- 대상 부위가 가득 찼으면 기존 모듈 하나를 고르는 교체 창을 표시한다.
- 플레이어는 증강 대신 확장 가능한 함선 부위를 골라 빈 슬롯을 1개 늘릴 수 있다.
- 부위별 슬롯 용량은 1에서 시작하며 최대 3이다.
- 카드 포커스·호버가 바뀌면 해당 카드의 대상 부위 하이라이트도 바뀐다.
- 슬롯은 숫자가 아닌 `18×18px` 둥근 사각 프레임으로 표시하고 설치 모듈 아이콘을 담는다.
- 확장 가능한 부위를 선택하면 다음 슬롯이 점멸하며, 카드와 부위 선택지는 모두 키보드로 조작할 수 있다.
- 적 증강 오퍼는 기존 동작을 유지한다.

## 결정

- 모든 플레이어 증강은 함선 부위 슬롯 하나를 차지한다.
- 교체로 제거된 모듈의 지속 효과와 무기 레벨 보너스도 제거된다.
- 동일 모듈 중복 장착과 효과 중첩을 허용한다.
- 무기 강화 모듈은 장착 시 선택한 무기 ID를 기억하며 장착 중에만 유효 레벨을 올린다.
- 교체 취소 시 기존 증강 선택 화면으로 복귀한다.

## 구현

- `PlayerAugmentRegistry`가 부위별 슬롯 용량과 설치 모듈의 단일 상태 출처다.
- 기존 `ShipFacilityRegistry`와 시설 레벨 API를 제거했다.
- 플레이어 오퍼, 대상 부위 하이라이트, 슬롯 확장, 교체 모달을 연결했다.
- 카드와 함선 부위의 방향키·Tab 포커스 경로와 `ui_accept` 선택을 연결했다.
- 슬롯·효과·무기 레벨·오퍼 UI 회귀 테스트와 실제 렌더 검증을 통과했다.
