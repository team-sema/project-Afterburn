# 통합 증강 테스트 랩

## 목표

- `C`로 플레이어, `V`로 적 강화 이벤트를 모의한다.
- 플레이어 시설 증강과 모든 적 증강을 스크롤 목록에서 직접 선택·적용한다.
- 기존 무기·특성·적 스폰 테스트 기능을 유지한다.

## 완료 조건

- PLAYER 시설 12종과 ENEMY 7종을 자동 발견한다.
- 무기 획득·레벨·특성은 기존 오른쪽 무기 UI로만 제어한다.
- 선택 결과가 랩의 플레이어·적 증강 레지스트리에 반영된다.
- 기존 랩 스모크 테스트와 프로젝트 파싱 검사를 통과한다.
