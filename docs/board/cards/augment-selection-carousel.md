# 증강 선택 캐러셀 UI

## 목표

- 전체 화면을 가리는 별도 선택 화면 대신 기존 우측 STATUS UI를 증강 결과 미리보기에 재활용한다.
- 중앙에는 원통형 캐러셀처럼 깊이감 있게 배치된 증강 카드 3장을 표시한다.
- 좌우 입력으로 포커스 카드를 회전시키고, 리롤은 현재 포커스 카드 한 장에만 적용한다.

## 완료 조건

- 포커스 카드는 전면에 강조되고 나머지 두 카드는 뒤쪽에서 어둡거나 반투명하게 표시된다.
- 세로형 카드 캐러셀과 선택창 외곽 전체를 좌우 STATUS 사이의 중앙 플레이필드 안에 배치하고 선택 중 별도 조작 설명 문구를 표시하지 않는다.
- 좌우 입력 시 세 카드가 실린더를 도는 전환 연출과 함께 포커스가 이동한다.
- 추가 모듈 슬롯 또는 신규 무기 획득 후보는 우측 UI의 대응 위치에서 점멸 미리보기를 제공한다.
- 시설 증강 후보는 우측 STATUS의 첫 빈 범용 슬롯에 시설 아이콘으로 점멸한다.
- 무기 모듈 후보는 우측 STATUS의 대상 무기와 장착 모듈 칸에서 다음 레벨 아이콘으로 점멸한다.
- 무기 슬롯이 가득 차 교체가 필요한 후보는 우측 UI 점멸 미리보기를 생략한다.
- 카드 아래에는 `[R] 리롤 (남은 횟수)` 단일 버튼만 노출되며, 실행 시 포커스된 증강만 새 후보로 바뀐다.
- 위·아래 입력으로 카드·리롤 버튼·범용 슬롯 확장 사이를 이동할 수 있다.
- 무기 Kind 포커스여도 하단 `범용 슬롯 +1`을 유지한다(최대 시 비활성).
- 좌우 키를 길게 누르면 키가 눌린 동안에만 최소 0.45초 간격으로 한 칸씩 회전한다.
- 키를 뗀 뒤에는 추가 회전을 예약하지 않으며, Godot 기본 좌우 포커스 이동으로 카드를 건너뛰지 않는다.
