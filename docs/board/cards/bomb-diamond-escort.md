# Bomb 드론 다이아몬드 호위

## 목표

Bomb를 Tanker와 함께 등장시키지 않고, Drone 4기가 둘러싼 5슬롯 다이아몬드 중앙에 배치한다.

## AC

- [x] `bomb_drone_diamond`이 Threat 2+ 풀에 등록된다.
- [x] 중앙 슬롯은 Bomb, 나머지 네 슬롯은 Drone이다.
- [x] 기존 Bomb 근접 기폭·범위 피해·고속 신관 증강이 유지된다.
- [x] 적 스폰 스펙과 스모크 테스트가 새 Encounter id와 편대 구성에 맞는다.
