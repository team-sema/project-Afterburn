## 1. 게임 개요

**갤럭시 메이헴**은 세로 스크롤 슈팅에 **플레이어 강화 ↔ 적 강화** 오그먼트 선택을 얹은 프로토타입입니다.

적을 처치하고 경험치(XP)를 모아 레벨업하면 플레이어 강화를, 일정 시간이 지나면 적 강화를 고르게 됩니다. 강해질수록 전장이 더 거칠어지는 **줄타기**가 핵심 재미입니다.

플레이어 강화는 무한히 쌓이지 않습니다. 고른 강화는 **함선 부위의 슬롯에 장착되는 모듈**이고 슬롯 수가 제한되어 있어서, 나중에는 **무엇을 넣고 무엇을 뺄지** 고르게 됩니다.

### 핵심 루프

1. 적 처치 → 점수·XP 오브 획득  
2. XP로 레벨업 → **함선 모듈** 3지선다: 모듈을 장착하거나 부위 슬롯을 확장 (일시정지)  
3. 약 60초마다 **적 강화** 3지선다 (일시정지)  
4. 슬롯이 차면 기존 모듈을 교체하며 빌드를 다듬고, 무기 픽업으로 화력을 올림  
5. 피격으로 함선 파괴 → 게임 오버 → 하이스코어 확인 → 메뉴

승리(스테이지 클리어) 조건은 없고, **생존·고득점**이 목표입니다.

## 2. 플레이 방법

### 목표

- 가능한 오래 생존하며 점수를 쌓는다.
- 함선 모듈과 무기 픽업으로 빌드를 키운다.
- 하이스코어를 갱신한다.

### 조작

| 입력 | 동작 |
|------|------|
| 방향키 또는 **WASD** | 함선 이동 |
| (자동) | 장착 무기 **자동 발사** |
| **스페이스** (또는 Enter) | 메뉴 시작 / 게임 오버에서 메뉴 복귀 |
| 마우스 클릭 · 방향키 · Tab · Enter | 일시정지 중 선택 (모듈 카드 / 함선 부위 / 교체 슬롯) |

### 진행 요약

- **함선 모듈 (플레이어 강화):** XP 요구량 충족 시 오퍼. 카드 3장 중 하나를 골라 대응 부위에 장착하거나, 하단 함선 그림에서 부위를 골라 그 부위의 **슬롯을 1칸 확장**한다.
- **부위와 슬롯:** 무기실·격납고·엔진·선체·레이더·실드 6부위. 각 부위는 빈 슬롯 **1칸으로 시작해 최대 3칸**까지 늘어난다.
- **모듈 교체:** 대상 부위가 꽉 찬 모듈을 고르면 교체 창이 열려 뺄 슬롯을 지정한다. 취소하면 오퍼 선택으로 돌아간다. **뺀 모듈의 효과는 즉시 사라진다.**
- **적 강화:** 플레이 시간 약 60초마다 오퍼 (적 체력·속도·포화 사격 등). 이쪽은 슬롯 없이 계속 누적된다.
- **무기:** 적 드롭 픽업으로 주무기·보조무기 획득·강화 (무기별 최대 레벨 3). 무기 강화 모듈은 **장착 중인 동안** 해당 무기 레벨을 1 올려준다.
- **선체·실드:** 좌측 HUD에 선체(HULL)와 실드(SHIELD)가 따로 표시된다. 실드가 1이라도 남아 있으면 그 피격 한 번을 **전부 막아내고** 실드가 0이 된다. 실드가 0일 때만 선체가 깎인다.

### 종료 조건

- 선체(HULL)가 0이 되면 약 1초 후 **게임 오버**.
- 점수·하이스코어 표시 후 스페이스로 메뉴 복귀.
- 새 런은 메뉴에서 다시 시작.
