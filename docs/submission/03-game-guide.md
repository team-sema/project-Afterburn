## 1. 게임 개요

**갤럭시 메이헴**은 세로 스크롤 슈팅에 **플레이어 강화 ↔ 적 강화** 오그먼트 선택을 얹은 프로토타입입니다.

적을 처치하고 경험치(XP)를 모아 레벨업하면 플레이어 강화를, 일정 시간이 지나면 적 강화를 고르게 됩니다. 강해질수록 전장이 더 거칠어지는 **줄타기**가 핵심 재미입니다.

플레이어 강화는 두 갈래입니다.

- **함선 모듈:** 시설 효과는 범용 슬롯에 장착되고, 슬롯이 차면 tag와 관계없이 무엇을 빼고 넣을지 고릅니다.
- **무기:** 획득·전용 모듈 강화는 같은 레벨업 오퍼에서 고르지만 **시설 슬롯을 쓰지 않습니다.** 장착 무기는 통합 베이에서 동시에 발사됩니다.

### 핵심 루프

1. 적 처치 → 점수·XP 오브 획득  
2. XP로 레벨업(**C**) → 3지선다: 함선 모듈 장착·슬롯 확장, 또는 무기 획득·전용 모듈 강화 (일시정지)
3. 약 30초마다 **적 강화** 3지선다 (일시정지)  
4. 시설 슬롯이 차면 기존 모듈을 교체하며 빌드를 다듬고, 무기 베이도 만석이면 교체(피교체 무기 성장 삭제)  
5. 피격으로 함선 파괴 → 게임 오버 → 하이스코어 확인 → 메뉴

승리(스테이지 클리어) 조건은 없고, **생존·고득점**이 목표입니다.

## 2. 플레이 방법

### 목표

- 가능한 오래 생존하며 점수를 쌓는다.
- 함선 모듈과 무기 베이로 빌드를 키운다.
- 하이스코어를 갱신한다.

### 조작

| 입력 | 동작 |
|------|------|
| 방향키 또는 **WASD** | 함선 이동 |
| (자동) | 장착 무기 **자동 발사** |
| **C** | XP 준비 시 플레이어 오그먼트 오픈 |
| **ESC** | 수동 일시정지 토글 |
| 스페이스 (또는 Enter) | 메뉴 시작 / 게임 오버에서 메뉴 복귀 |
| 마우스 클릭 · 방향키 · Tab · Enter | 일시정지 중 선택 (모듈 카드 / 함선 부위 / 교체 슬롯) |

### 진행 요약

- **함선 모듈:** XP 요구량 충족 후 **C**. 카드 3장 중 시설 모듈을 골라 범용 슬롯에 장착하거나 **범용 슬롯 +1**을 선택한다.
- **범용 슬롯과 tag:** 시작 **5칸 → 최대 15칸**의 5×3 육각 벌집. 무기실·동력로·엔진·선체·레이더·실드 구분은 장착 제한이 아닌 module tag로 남고, 장착 슬롯 아이콘에 임시 표시된다.
- **모듈 교체:** 범용 슬롯이 꽉 차면 교체 창에서 뺄 슬롯을 지정. 취소하면 오퍼로 복귀. **뺀 모듈 효과는 즉시 사라진다.**
- **무기:** 같은 오퍼에서 획득·전용 모듈을 선택. 필드 무기 드롭과 무기 자체 레벨은 없다. 전용 모듈은 Lv.I~III으로 성장한다. 만석에서 새 무기를 고르면 피교체 무기의 모듈 레벨은 삭제된다.
- **적 강화:** 플레이 시간 약 30초마다. 슬롯 없이 누적.
- **선체·실드:** 좌측 HUD. 실드는 버퍼 HP — 피해는 실드를 먼저 깎고 남는 양만 선체에 들어간다.

### 종료 조건

- 선체(HULL)가 0이 되면 약 1초 후 **게임 오버**.
- 점수·하이스코어 표시 후 스페이스로 메뉴 복귀.
- 새 런은 메뉴에서 다시 시작.
