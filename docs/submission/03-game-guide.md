## 1. 게임 개요

**갤럭시 메이헴**은 종스크롤 슈팅에 뱀파이어 서바이버 스타일의 **증강 선택**을 얹은 로그라이트 게임입니다.

적을 처치해 경험치(XP)를 모으면 **내 함선을 강화**하는 선택지를 받습니다. 하지만 시간이 흐르면 **적을 강화**하는 카드 선택지들도 받게 되고, 그 중 반드시 **하나를 골라야 합니다**. 즉 플레이어는 자기 빌드를 키우는 동시에, **자신이 상대하는 적들이 어느 방향으로 진화할지**까지 스스로 결정합니다.

### 이 게임의 차별점


|               |                                                                                          |
| ------------- | ---------------------------------------------------------------------------------------- |
| **양방향 증강**    | **플레이어 강화과 적 강화**를 모두 플레이어가 직접 고르며 진행합니다. 적 강화는 건너뛸 수 없어, "차악"을 고르는 선택이 매 판 다른 위기를 만듭니다. |
| **모듈 조립형 빌드** | 무기 7종 중 3개까지 선택하여 장착할 수 있고, 각 무기는 강화할 수 있는 전용 부슬롯 4개를 가집니다.                              |




### 핵심 루프

1. 적을 처치해 XP 오브를 습득한다.
2. XP가 차면 원하는 타이밍에 **C**로 플레이어 증강 선택 화면을 연다.
3. 등장 시퀀스의 엘리트 관문을 처치하면 탄막·XP 정산 후 위협도(THREAT)가 오르고 **적 증강** 카드 3장 중 하나를 고른다.
4. 강해진 적을 상대로 더 강해진 내 빌드를 검증하며, 끝까지 살아남는다.

## 2. 플레이 방법



### 목표

- 가능한 오래 생존하며 점수를 쌓고 하이스코어를 갱신한다.
- 무기 · 모듈 · 함선 시설을 조합해 자신만의 빌드를 완성한다.



### 조작


| 입력              | 동작                           |
| --------------- | ---------------------------- |
| 방향키 또는 **WASD** | 함선 이동 (사격은 자동)               |
| **C**           | XP 충족 시 플레이어 증강 카드 열기        |
| **SHIFT**       | 긴급 회피 부스터 (`비상 부스터` 모듈 장착 시) |
| **ESC**         | 수동 일시정지 토글                   |
| Enter · 마우스     | 선택 확정                        |
| **R**           | 증강 선택 리롤                     |
| 스페이스 (또는 Enter) | 메뉴 시작 / 게임 오버에서 메뉴 복귀        |




### 화면 구성

3분할 HUD로, 전투 중에도 빌드 상태를 계속 볼 수 있습니다.


| 영역     | 표시                                                                  |
| ------ | ------------------------------------------------------------------- |
| **좌측** | SCORE · XP 게이지 · STAGE(현재 스테이지·시퀀스 진행도) · HULL(선체) · SHIELD(실드와 재충전 게이지) |
| **중앙** | 플레이필드                                                               |
| **우측** | STATUS — 공용 슬롯(최대 15칸) · 무기 슬롯 3칸                                   |

증강선택

### 진행 요약

- **플레이어 증강:** XP 요구량을 채우면 HUD에 `AUGMENT READY [C]`. 증강 선택이 끝나면 주위 작은 범위 탄막이 소거되므로, 위기 탈출용으로도 사용 가능합니다.
- **함선 시설 모듈:** 카드 3장 중 하나를 골라 **범용 슬롯**에 장착. 시작 5칸 → 최대 15칸.
- **슬롯 확장:** 어떤 카드를 뽑았든 하단의 `범용 슬롯 +1`을 고를 수 있습니다. 당장의 강화와 향후 슬롯 여유 중 어디에 투자할지 고르는 선택입니다.
- **모듈 교체:** 슬롯이 꽉 차면 교체 창에서 뺄 모듈을 지정합니다.
- **무기:** 증강 카드로 획득하며 최대 3개 동시 장착. 전용 모듈은 Lv.III까지 성장시킬 수 있습니다.
- **선택 미리보기:** 카드에 포커스하면 장착될 범용 슬롯이나 무기 모듈 위치가 우측 STATUS에서 점멸합니다.
- **리롤:** 현재 포커스한 카드 1장만 교체합니다.
- **적 증강:** 엘리트 관문 처치·XP 정산 후 3지선다.
- **선체 · 실드:** 실드는 선체를 먼저 막는 버퍼 체력이며 일정 시간마다 1씩 재충전됩니다.
- **피격 · 위험 표시:** 모든 피격 피해는 1이며, 피격 후 0.6초 무적이 적용됩니다. 조준선·진입 경고·폭발 범위로 주요 공격을 미리 표시합니다.



### 종료 조건

- 선체(HULL)가 0이 되면 **게임 오버**. 최고 점수는 하이스코어로 기록됩니다.

## 3. 콘텐츠 볼륨


| 항목               | 수량      | 비고                                              |
| ---------------- | ------- | ----------------------------------------------- |
| 플레이어 증강 카드       | **48종** | 시설 모듈 13 + 무기 획득 7 + 무기 전용 모듈 28                |
| 무기               | **7종**  | 블래스터 · 레이저 · 샷건 · 보조 캐넌 · 플라즈마 폭탄 · 유도탄 · 궤도 방벽 |
| 무기 전용 모듈         | **28종** | 무기당 4종 × 최대 Lv.III (효과 수치가 레벨마다 재정의)            |
| 함선 시설 모듈         | **13종** | 무기실 · 동력로 · 엔진 · 선체 · 레이더 · 실드 6계열              |
| 적 증강             | **6종**  | 체력·속도·화력 강화 + 임사 체험 · 드론 증원 · 고속 기폭             |
| 적 유닛             | **8종**  | 아래 표                                            |
| 편대 조우(Encounter) | **13종** | 위협도에 따라 해금되는 편대 구성·진입 경로                        |


각 무기에 부가적으로 적용되는 모듈을 통해 다채롭게 기본 무기를 진화시켜 나갈 수 있습니다. 예를 들어 샷건은 `확장형 탄피`로 펠릿을 8발 늘려 광역화하거나, `초크 튜브`로 산탄각을 조여 장거리 관통형으로 만들 수 있습니다. 같은 무기라도 어떤 모듈을 먹었는지에 따라 **완전히** 다른 무기가 됩니다.

## 4. 비주얼 · 사운드

- **Nova Drift 풍 네온 룩** — 모든 기체와 탄이 `코어 + 3단 글로우 레이어`로 구성되고, HDR 블룸을 얹어 어두운 우주 배경 위에서 빛나도록 만들었습니다.
- **SVG 아트** — 벡터 아트로 제작된 적·무기·HUD 아이콘이 경우에 따라 적절하게 pixelated 되어 표기됩니다.
- **3단 패럴랙스 우주 배경**과 적들의 피격 플래시 · 스케일 펀치 · 흔들림으로 타격감을 보강했습니다.
