## 2. 역할 구분


| 역할      | 이재현                                   | 최민용                                      |
| ------- | ------------------------------------- | ---------------------------------------- |
| 게임 기획   | 플레이어 성장, 증강 선택 경험, 무기별 전투 감각          | 적 조우 구성, 위협도 진행, 무기 장착·시설 효과 규칙          |
| 게임 개발   | 초기 씬·플레이어 흐름, 증강 선택 시스템, 무기별 동작        | 적·편대·인카운터 시스템, 장착·교체·시설·실드 시스템           |

| 도구·문서   | 무기·증강 테스트 환경                          | 기획·칸반 사이트, 개발 문서 관리                      |




### 이재현 — 플레이어 경험과 비주얼 방향

플레이어가 직접 조작하고 선택하는 영역의 기획·개발 담당. 초기 씬과 플레이어 흐름, 증강 선택, 무기별 동작을 구현하고 관련 UI와 시각 효과를 제작.

### 최민용 — AI 개발 워크플로와 콘텐츠 시스템

Cursor 룰·스킬과 `/feature`·`/push` 자동화, 기획·Task·칸반 연동 구조 설계·구현. 적 조우·장착 구조 기획과 적·인카운터·STATUS HUD 구현 담당.

---



## 3. 협업 방식

- Cursor 룰·스킬과 `/feature`·`/push`를 팀 공통 워크플로로 사용
- 기능별 담당자 1인이 `feature/<slug>` 브랜치 담당
- `docs/design/`에 의도·동작·수치·완료 조건, **Notion 칸반**에 진행 상태·티켓
- 기능 담당자가 구현·완료 조건 확인, 다른 팀원이 실제 플레이로 교차 검증
- Cursor Agent 초안은 기능 담당자가 검토·반영하며, 세부 활용 방식은 제출물 4에 별도 정리
