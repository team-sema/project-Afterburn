# Bomb 엘리트 외형 시안

- 브랜치: `feature/elite-bomb-design`
- 정본: [Bomb](../enemies/bomb.md)
- 범위: Bomb 문서, 엘리트 Bomb SVG와 문서용 사본, 미리보기 PNG와 렌더 스크립트, 이 작업 기록.

## 작업·검증

- [x] 기존 Bomb와 엘리트 조형 확인 및 정본에 시안 설명 추가.
- [x] SVG 제작과 문서용 사본 추가.
- [x] Godot에서 비교 이미지 렌더링 PASS (종료 코드 0), 확대·실제 크기 확인.
- [x] 문서용 SVG와 원본 해시 일치, diff 공백 검사.

Direct3D 미리보기에서 글자가 누락되어 최종 이미지는 OpenGL Compatibility로 렌더링했다. 렌더 종료 시 ObjectDB 인스턴스 정리 경고가 별도로 출력된다. 이미지 저장과 글자·실루엣 확인은 성공했다.

전투 동작 및 스폰 연결은 이번 작업 범위에 포함하지 않는다.

- 수정 시안: 상단 신관을 제거하고 사방 대칭의 장갑 기뢰로 변경. 비교 이미지 재렌더 PASS, 문서용 사본 일치 및 공백 검사 통과.
