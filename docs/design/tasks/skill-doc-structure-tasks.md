# 프로젝트 스킬 문서 구조 대응

기준: [Feature 작업 방식](../feature-workflow.md), [기획서 운영 원칙](../README.md).

## 범위

프로젝트용 feature 시작·완료·merge 스킬과 Cursor 호환 스킬. 게임 코드·씬·리소스는 수정하지 않는다.

## 작업

- [x] 새 통합 문서 구조에서 정본 기획서를 선택하는 기준을 명시한다.
- [x] 기존 문서의 문맥을 유지하며 본문·표·완료 조건을 직접 갱신하도록 한다.
- [x] `이번 변경`에 쌓인 완료 내용을 현재 규칙에 통합하도록 push 검증을 보강한다.
- [x] history·과거 Task·중복 규칙을 현재 구현 기준으로 오인하지 않도록 한다.
- [x] skill frontmatter와 프로젝트 내 옛 문서 경로 참조를 검증한다.

## 검증

- `quick_validate.py`로 `.agents/skills/afterburn-*`를 검사한다.
- 수정한 스킬과 프로젝트 지침에서 통합 전 문서 경로 참조가 남지 않았는지 검색한다.
- diff가 문서·스킬 범위에 한정되는지 확인한다.
