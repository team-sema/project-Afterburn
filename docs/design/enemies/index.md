# 적 기획 (의도·역할)

**기획 문서.** “왜 이 적인가 / 플레이어에게 무슨 압박인가”만 적는다.  
HP·사격·Encounter → [구현 스펙 · 적](../spec/#enemies) · [Encounter](../spec/#encounters).

층 규칙: [doc-layers](#layers)

## 로스터 한눈에

| 적 | 기획 의도 (한 줄) | 구현 |
|----|-------------------|------|
| Drone | 기본 탄압·편대 밀도. “잡몹”이지만 무시하면 맞음 | [spec](../spec/#enemies/drone) |
| Striker | 호위 편대의 **핵**. 끊으면 산개·돌진으로 판이 바뀜 | [spec](../spec/#enemies/striker) |
| Awl | 텔레그래프 후 **돌진**. 투사체 대신 몸박 위협 | [spec](../spec/#enemies/awl) |
| Bomb | **공간 압박**. 가까이 가면 폭발·범위 | [spec](../spec/#enemies/bomb) |
| Interceptor | 측면 고속 통과. 짧게 보고 피하거나 맞기 | [spec](../spec/#enemies/interceptor) |
| Caster | 상단 체공 **탄막 장판**. 회피 동선 강제 | [spec](../spec/#enemies/caster) |
| Sniper | 조준 선으로 **위치 이탈**을 요구 | [spec](../spec/#enemies/sniper) |
| Elite | Threat 관문. 처치해야 적 강화 선택·난이도 상승 | [spec](../spec/#enemies/elite-fighter) |

상세가 필요하면 아래 개별 MD를 늘린다. 없으면 이 표가 기획 정본이다.
