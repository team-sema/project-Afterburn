# 적 기획

각 적이 **왜 있는지 / 플레이어에게 무슨 결정을 강제하는지**.  
왼쪽 네비로 타입별 문서로 들어가고, 수치·사격·Encounter는 **구현 스펙**으로 이어진다.

| Drone | 편대 밀도와 기본 탄압 | [기획](#enemies/drone) | [spec](../spec/#enemies/drone) |
| Striker | 호위 편대의 핵 · 끊으면 판이 바뀜 | [기획](#enemies/striker) | [spec](../spec/#enemies/striker) |
| Awl | 텔레그래프 후 돌진 · 몸박 | [기획](#enemies/awl) | [spec](../spec/#enemies/awl) |
| Bomb | 접근 비용 · 공간 압박 | [기획](#enemies/bomb) | [spec](../spec/#enemies/bomb) |
| Interceptor | 측면 고속 통과 · 짧은 교전 | [기획](#enemies/interceptor) | [spec](../spec/#enemies/interceptor) |
| Caster | 상단 탄막 장판 | [기획](#enemies/caster) | [spec](../spec/#enemies/caster) |
