# Elite Fighter — 기획

## 의도

**Threat 관문**.  
시간이 차면 일반 웨이브와 다른 “보스 아닌 중간 보스”로 리듬을 끊는다. 잡기 전에는 난이도(Threat)·적 강화 선택이 안 열리게 해, **처치가 진행의 열쇠**가 되게 한다.

## 플레이어에게 강제하는 것

- 일반 잡몹과 다른 집중 교전
- 관문 중에는 웨이브 처리보다 엘리트 우선
- 처치 후 적 오그먼트 선택으로 다음 구간의 규칙이 바뀜을 체감

## 하지 않는 것

- 일반 Encounter 풀에 섞인 “좀 센 잡몹”
- 아직 없는 풀 보스 챕터 대체 (보스는 별도 TBD)
- 처치 없이 Threat만 오르는 타이머 보상

## 조합에서의 자리

MainEncounterPool과 분리된 전용 스폰. 페이싱·게이트는 런 문서.
