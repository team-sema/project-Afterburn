# Elite Fighter — 기획

## 의도

**Threat 관문**.  
시간이 차면 일반 웨이브와 결이 다른 “보스 아닌 중간 보스”로 리듬을 끊는다. 잡기 전에는 Threat·적 강화 선택이 열리지 않아, **처치가 다음 구간으로 가는 열쇠**가 된다.

## 플레이어가 고민할 점

- 일반 잡몹과 다른 집중 교전
- 관문 중에는 웨이브보다 엘리트를 우선하기
- 처치 후 적 오그먼트 선택으로, 다음 구간의 규칙이 바뀌는 걸 체감하기

## 하지 않는 것

- 일반 Encounter 풀에 섞인 “조금 센 잡몹”
- 아직 없는 풀 보스 챕터를 대신하는 존재 (보스는 별도 TBD)
- 처치 없이 Threat만 올려 주는 타이머 보상

## 편대·Encounter에서의 역할

MainEncounterPool과 분리된 전용 스폰. 언제 뜨는지·게이트 규칙은 런·페이싱 문서를 본다.
