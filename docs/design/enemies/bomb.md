# Bomb — 기획

## 의도

**가까이 가면 대가를 치르는** 적.  
없애기 전에 “얼마나 붙어도 되는지”를 고민하게 만드는 **공간 압박**. 다가가면 멈추고 점멸한 뒤 폭발한다. 욕심내면 맞는다.

## 플레이어가 고민할 점

- 사거리와 위치 관리 (들이받지 않기)
- 호위 Drone을 뚫고 Bomb만 노릴지, 거리를 유지할지
- 폭발 범위(자신·주변 적)를 읽고 위험을 감수할지

## 하지 않는 것

- 원거리 탄막이 주력인 적 (Caster / Sniper 몫)
- 혼자 화면을 메우는 잡몹 웨이브 (호위와 세트로 읽히게)
- 예고 없이 즉사시키는 근접 (점멸·프리뷰로 읽을 시간을 준다)

## 편대·Encounter에서의 역할

단독 Encounter는 없다. 다이아몬드 중앙 + Drone 호위가 기본 읽기다.
