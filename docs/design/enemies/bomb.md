# Bomb — 기획

## 의도

**접근 비용**.  
쏴서 없애기 전에 “얼마나 가까이 가도 되는가”를 고민하게 하는 **공간 압박**. 다가가면 멈추고 점멸하며 폭발 — 욕심내면 맞는다.

## 플레이어에게 강제하는 것

- 사거리·위치 관리 (들이박지 말 것)
- 호위 Drone을 뚫고 Bomb만 노릴지, 거리를 둘지
- 폭발 범위(자신·주변 적)를 읽고 도박할지

## 하지 않는 것

- 원거리 탄막 주력 (Caster/Sniper)
- 단독으로 화면을 메우는 잡몹 웨이브 (호위와 세트로 읽히게)
- 경고 없는 즉사 근접 (점멸·프리뷰로 읽을 시간)

## 조합에서의 자리

단독 Encounter 없음. 다이아몬드 중앙 + Drone 호위가 기본 읽기.
