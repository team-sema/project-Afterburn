# Striker — 기획

## 의도

호위 편대의 **핵**. Drone 구름 뒤에 있어 “어디를 먼저 부술지”를 고르게 한다.  
핵을 끊으면 편대가 풀리며 **산개·돌진**으로 판의 성격이 바뀐다 — 정리한 보상이자 2차 위협.

## 플레이어에게 강제하는 것

- 호위 밀도 속에서 핵 우선순위 판단
- 해제 후 돌진 각을 피할지, 미리 깎아 둘지
- 산개한 Drone 잔당을 무시할지 청소할지

## 하지 않는 것

- 단독으로 화면을 지배하는 탄막기 (Caster/Sniper)
- 자폭 공간 압박 (Bomb)
- “그냥 두꺼운 Drone” — 핵으로서의 역할이 있어야 함

## 조합에서의 자리

Diamond 호위 편대의 꼭짓점/후방. 레거시 단독 프리셋은 풀 밖.
