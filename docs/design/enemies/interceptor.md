# Interceptor — 기획

## 의도

**측면·대각의 짧은 교전**.  
위에서 천천히 내려오는 편대와 달리, 좌우에서 경고 후 빠르게 스쳐 가며 한 번 갈긴다. “세로 스크롤만 보면 맞는다”는 감각을 깨뜨린다.

## 플레이어에게 강제하는 것

- 가장자리 경고를 보고 시선·히트박스 옮기기
- 짧은 사격 창에만 반응 (질질 끄는 교전 아님)
- 통과 후 추격 가치가 있는지 판단 (이탈하면 보상 없음 — 구현)

## 하지 않는 것

- 상단 장기 체공 탄막 (Caster)
- 느린 하강 편대의 대체재
- 화면 중앙에 눌러앉는 저격 (Sniper)

## 조합에서의 자리

2기(pair)·3기(trio). 단독 배회형 Encounter는 두지 않음.
