# Awl (Kamikaze) — 기획

## 의도

탄이 아니라 **몸이 무기**.  
편대로 내려온 뒤 텔레그래프(차징) → 각자 돌진. “지금 피할지, 사선에서 미리 지울지”를 짧게 결정하게 한다.

## 플레이어에게 강제하는 것

- 차징 타이밍 읽기
- 돌진 축에서 벗어나기 / 선제 격파
- 투사체 회피와 다른 종류의 공간 압박

## 하지 않는 것

- 원거리 탄막 주력
- 조용한 잠입 (등장·차징이 보여야 함)
- Bomb처럼 범위 폭발로 주변까지 지우는 역할 (그건 Bomb)

## 조합에서의 자리

V자 3기 편대가 기본. 하강 구간만 형태 유지 후 분리.
