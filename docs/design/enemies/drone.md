# Drone — 기획

## 의도

화면을 채우는 **기본 밀도**와 **무시하면 맞는 탄압**.  
“잡몹”이지만 가만히 두면 편대가 플레이 공간을 잠식한다. 초반부터 등장해 **이동·사격 리듬의 바닥**을 만든다.

## 플레이어에게 강제하는 것

- 편대 전체 vs 핵만 자를지 선택 (호위일 때)
- 산개·대각 이동 경로를 미리 읽기
- DPS를 분산할지 한 줄부터 지울지

## 하지 않는 것

- 단독 보스급 위협
- 긴 텔레그래프 특수기 (그건 Sniper/Awl/Bomb)
- 화면 전체를 덮는 탄막 (Caster)

## 조합에서의 자리

거의 모든 편대의 **살·호위**. Striker·Bomb·Caster 궤도 등의 몸통.  
편대 기하·이동 수치는 구현 스펙·Encounter 쪽.
