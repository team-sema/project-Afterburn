# Sniper — 기획

## 의도

**조준선으로 위치 이탈을 강제**한다.  
맞기 전에 “지금 서 있는 곳이 죽는 자리”라는 걸 보여 주고, 움직이거나 끊게 만든다. 전방 Tanker 등과 묶이면 “앞을 막은 채로 뒤를 노리는” 읽기가 생긴다.

## 플레이어에게 강제하는 것

- 조준 수렴 타이밍에 자리 비우기
- 엄폐·전방 실드(가드) 너머 우선순위
- 가만히 DPS만 넣는 플레이 금지

## 하지 않는 것

- 무경고 고속 즉사탄 (선이 보여야 함)
- 화면을 메우는 다연발 장판 (Caster)
- 돌진 몸박 (Awl)

## 조합에서의 자리

가드+Sniper 편대가 기본. 탱커가 이미 있으면 단독 보강으로 대체될 수 있음 (구현).
