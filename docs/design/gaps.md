# 미결정·확장 후보

현재 규칙은 각 주제 문서에서 관리한다. 아래는 미구현 또는 의도 결정이 필요한 항목이며 구현 지시가 아니다. 완료 항목·파일 개수·단순 이름 정리 목록은 유지하지 않는다.

## 콘텐츠·동작 결정

- **보스:** [Wall](bosses/wall.md) 프로토타입이 메인 시퀀스 `d`에 연결됐다. 수치·패턴·포탑 파괴 등은 체감 후 조정. [거대 항모](bosses/carrier.md)는 Boss Lab 전용이며 본 게임 시퀀스·보상에 연결되지 않았다.
- **런 구조:** 장 구분·런 클리어 조건·결과 화면이 없다. 시퀀스는 마지막 Phase를 무한 반복하고 런은 플레이어 사망으로만 끝난다([런 페이싱](run-pacing.md)).
- **Striker 편대 해제:** [Striker의 확인 필요](enemies/striker.md#확인-필요). 기존 의도와 현재 이동 완료 기반 해제가 다르다.
- **플레이어 행동 증강:** PlayerAugment.behavior_components는 있으나 PlayerAugmentApplier가 부착하지 않는다. 후보는 [오그먼트](augments.md#미결정-후보).
- **탄막 후속 API:** [전투](combat.md)의 탄→탄 SPAWN은 설계만 있다. 반사 계열 증강(방벽이 적탄을 되쏨 등)에 필요한 적탄 소유권 전환(적탄 → 플레이어 탄)은 설계 전이다.
- **플레이 체감 검증:** 초반 일반 적의 회피 여유, 네 엘리트의 체감 난도·교전 시간(특히 Elite Bomb 기뢰 범위·Elite Caster 주문별 밀도), 프리즘 카드 11종의 강약과 대가는 실제 플레이로 확인할 필요가 있다.

## 확장 시 고려

- 일반 적 사격 안전선은 EnemyAugmentRegistry가 런 공통값을 소유한다. 별도 전투 설정이나 안전선 증강을 추가할 때 기본값과 런타임 보정의 소유권을 검토한다.
- 마스터 볼륨·저장은 구현되어 있다. 종합 설정 메뉴를 추가할지는 미결정이다.
