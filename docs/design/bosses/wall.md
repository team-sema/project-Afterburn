# Boss Wall (프로토타입)

## 구현 상태

플레이 경험 확인용 최소 프로토타입. 메인 시퀀스 BOSS 토큰 `d`. Phase `main` 패턴 끝(`… a a a a d`)에서 등장한다.

목표 루프: **회피 → 포탑·코어 등장 → 나선형 탄막 사이로 접근 → 약점(코어) 공격 → 다시 회피**.

## 외형

![Boss Wall](../enemies/sprites/boss_wall.svg)

화면 상단을 **전폭(240px)** 가리는 방벽. 슬롯에서 시안 포탑과 **마젠타 약점 코어**가 함께 노출된다.
- 본체: `assets/enemies/boss_wall.svg` — 밝은 코어 + 분홍 글로우 (원래 틴트)
- 개방구: `assets/enemies/boss_wall_bay.svg` — 시안 림
- 포탑: `assets/enemies/boss_wall_turret.svg` — 밝은 시안
- 코어: `assets/enemies/boss_wall_core.svg` — 강한 마젠타 발광·펄스

## 의도

벽은 항상 위에 있고 때리면 **거의 안 깎인다**. 포탑이 열릴 때만 “지금 때려야 한다”가 보이게 한다. 탄막은 도망용 벽이 아니라, **빈 공간을 따라 움직이며 코어에 딜하는** 느낌.

## 플레이어가 고민할 점

- 회피 페이즈에서 칩 데미지만 나는 벽을 때릴지 말지
- 포탑·코어가 뜬 슬롯으로 탄막 사이를 파고들 타이밍
- 포탑을 먼저 부숴 코어 노출을 늘릴지, 코어만 집중할지

## 하지 않는 것 (이 프로토타입)

- 추가 탄막 패턴·페이즈 분기
- 보스 체력바 UI
- 측면 돌파 전용 기믹

## 전투

진입: y=32 이동(48px/s) 후 정지 — 스프라이트 높이 64 기준 **상단 y=0에 밀착**.

### 사이클 (포탑 2~3개 동시)

1. **회피** — 휴식 **4~6초**
2. **등장** — 좌·중·우 중 **2~3슬롯** 동시
3. **활성 ~8초** — 엇갈린 나선 사격 + 코어 노출
4. **퇴장** — 전부 파괴 시 코어 **+2.5초** 추가 노출

### 피격·피해

| 대상 | 피해 | 피드백 |
|------|------|--------|
| 벽 본체 | 수신 데미지의 **8%** (최소 1) · **관통 차단** | **없음** (피격 이펙트만 제거) |
| 약점 코어 | **100%** (보스 HP) | 포탑(또는 코어) 로컬 펀치만 |
| 포탑 | 포탑 자체 HP만 | 포탑 로컬 스케일·플래시 |

벽 Hurtbox는 베이 슬롯 세로 틈을 남겨 포탑/코어만 직접 조준 가능. `blocks_pierce = true`.

### 탄막 (나선 · 템포)

- 탄종: **구형(round)**, 탄속 **42** — 각 포탑 **Muzzle**에서만 발사
- **웨이브 3회**: 포탑마다 SINGLE 5발 나선 버스트 → 포탑 전환 0.4초 → 웨이브 사이 **1.25초 휴지**
- 웨이브 종료 후 활성 시간 동안은 대기(무한 연사 없음)
