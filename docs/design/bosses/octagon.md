# 옥타곤 — 회전 방어환 Lab

## 의도·범위

Broken Orbit의 보스 후보. 쇼크 트루퍼스 2nd Squad 최종 보스의 거대한 회전체 가장자리와 개별 파괴 무장을 참고한다. 전체 고리를 축소해서 보여주지 않고, 화면 밖 중심을 기준으로 회전하는 고리의 아래쪽과 인접 포탑 두 개만 크게 보여준다. 시각 기준은 [교전 시안](../../concept-art/2026-10-08/04-orbital-ring-combat-v1.png)이며 기존 항모 SVG의 분리 장갑·기하 코어·네온 표현을 따른다.

이번 구현은 틀과 교전 구도 검증용 Lab이다. 고리 SVG와 공통 포탑 8개, 회전·개방·공통 사격·부위 파괴까지만 구현한다. 8종 고유 무장, 조합별 패턴, 메인 런 연결·보상·최종 격침 연출은 후속 범위다.

## Lab 규칙

- 전장 300×360. 고리 중심 (150, -132), 포탑 장착 반경 240px, 45도 간격 8개. 교전 정렬 시 아래쪽 양옆 모듈 중심은 약 (58, 90), (242, 90)이다. 고리 틀은 안쪽 반경 170px~바깥 반경 228px이며 몸체 접촉 판정은 없다.
- 인접 두 개만 개방·피격·사격한다. 화면 밖 포탑과 회전·개폐 중 포탑은 피해를 받지 않는다. 고리와 장착부는 함께 회전한다.
- 개방 0.55초 → 교전 4.5초 → 폐쇄 0.45초 → 한 칸 회전 1.8초. 인접 쌍은 1+2 → 2+3 → … → 8+1 순서다. 모두 파괴된 쌍은 건너뛰되 물리적 회전 경로를 유지한다.
- 공통 포탑은 각 180 HP. 교전 중 0.65초 충전 뒤 화면 아래 방향으로 정렬한 포신에서 3방향 부채꼴(±12도), 탄속 85px/s, 발사 후 휴식 0.9초. 좌우 첫 발사는 0.45초 어긋난다. 상세 무장 확정이 아닌 임시 공통 패턴이다.
- 파괴한 포탑은 어두운 잔해로 고리에 남고 다시 회전해 온다. 파괴 부위의 발사·판정은 즉시 꺼진다. 마지막 포탑 파괴 시 회전과 사격을 멈추고 잔존 적탄을 정리한다. 중복 피해·과잉 피해는 HP를 중복 차감하지 않는다.
- 실제 함선 이동·자동 사격을 사용하며 생존 보장, 피격 수·전체 HP·활성 쌍을 표시한다. 이동 영역은 x=10~290, y=160~346으로 교전 하단에 둔다. Lab의 배경은 낮은 밝기로 누르고 배경용 궤도 링은 꺼서 보스 고리 틀과 구분한다. XP·점수·런 진행은 만들지 않는다.
- R 재시작, P 일시정지, N 다음 쌍(현재 공격을 접고 회전), F1 허브 복귀. 같은 기능을 방향키+확인으로 접근 가능한 버튼으로 제공한다. 일시정지는 회전·개방·사격·탄 이동을 함께 멈춘다.

## 완료 조건·검증

`tests/labs/octagon_boss_lab_smoke_test.gd`: 8개 방사 배치, 두 개만 교전, 실제 플레이어 탄 피해, 화면 밖 피해 차단, 회전 후 인접 쌍 교대, 잔해 유지·중복 피해 차단, 일시정지·재시작·전부 파괴 종료를 검사한다. 창 실행으로 원호가 좌우 밖으로 이어지는 크기, 포탑 판독성, 하단 회피 공간을 확인한다.

현재 검증: 전용 회귀 테스트 PASS(스크립트 오류 0), D3D12 창 실행의 교전·회전 화면 확인. Godot 종료 시 ObjectDB/리소스 정리 경고는 별도로 남는다. 실제 플레이의 크기·회전 속도·교전 시간 체감은 Lab에서 조정할 대상이다.
