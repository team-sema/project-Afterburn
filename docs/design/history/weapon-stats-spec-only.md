# Feature: 무기 수치는 스펙만

> 과거 기능 작업의 설계·결정 이력입니다. 아래 수치·상태·문서 운영 지침은 당시 기록이며 현재 구현 기준이 아닙니다. 현재 기준은 [통합 기획서](../README.md)를 따릅니다. 미구현 제안은 별도 확정 없이 구현하지 않습니다.

## 목적

무기 전투 기본값은 `docs/design/player.md`에서 트래킹한다. STATUS HUD에는 이름·레벨·설명·특성만 두고 **수치 줄을 표시하지 않는다**.

## 규칙

1. `WeaponSystem.get_status_stat_line` / `get_weapon_stat_summary` / STATUS 푸터 수치 줄을 제거한다.
2. 기본 전투 수치는 `docs/design/player.md` 표에 씬 익스포트 기준으로 적는다.
3. 인게임 디테일 푸터는 무기/특성 **설명만** 보여 준다.

## AC

- [x] STATUS 푸터에 피해·간격 등 전투 수치 없음
- [x] `docs/design/player.md`에 7종 기본 수치 표
- [x] 관련 스모크 통과
