# 엘리트 전투 패턴 개선

> 과거 기능 작업의 설계·결정 이력입니다. 아래 수치·상태·문서 운영 지침은 당시 기록이며 현재 구현 기준이 아닙니다. 현재 기준은 [통합 기획서](../README.md)를 따릅니다. 미구현 제안은 별도 확정 없이 구현하지 않습니다.

Threat 관문이 충분한 교전 시간을 확보하고, 공격별로 다른 회피 판단을 요구한다.

- 기본 체력과 Threat당 증가량을 높인다. 확정 수치는 [현황 스펙](../enemies/elite-fighter.md)을 따른다.
- 진입 후 이동하며 부채꼴 견제 → 정지·방향 고정 예고 → 집중 사격 → 이동·휴식 순으로 반복한다.
- 예고 후에는 플레이어를 재추적하지 않아 사선을 벗어나는 회피가 유효하다.
- 체력 기반 단계 변경은 사용하지 않는다. 집중 사격은 항상 3방향 10회, 부채꼴은 5방향 4회를 유지한다.
- 기존 적탄 생성·적 증강·이동 시퀀스와 Threat 처치 보상 흐름을 재사용한다.
- 엘리트 기체는 흰색 SVG·투명 절단면·쌍발 후방 하우징을 공유한다. 사격형은 넓은 어깨와 전방 포드, Awl 강화형은 긴 관통부와 측면 발사부로 구분한다.
- 돌격형은 Awl 강화형 기체를 사용한다. 플레이어 추적·컨베이어 띠 예고 → 대각선 돌진·양측 화염 → 화면 이탈 → 상단 재진입을 반복한다.
- 방향은 준비 중 부드럽게 추적하고 마지막 0.18초만 고정한다. 측면·하단·상단 어느 경계로 이탈해도 재진입하며, 체력 기반 패턴 변화는 없다.
- 첫 관문은 사격형, 다음 관문은 돌격형으로 번갈아 등장한다. 두 타입의 체력·보상은 같은 공식을 사용한다.
