# 제출 문서 한국어 카피 정리

> 과거 기능 작업의 설계·결정 이력입니다. 아래 수치·상태·문서 운영 지침은 당시 기록이며 현재 구현 기준이 아닙니다. 현재 기준은 [통합 기획서](../README.md)를 따릅니다. 미구현 제안은 별도 확정 없이 구현하지 않습니다.

제출용 MD(`docs/submission/`)의 플레이어 대면 표기를 인게임·의도된 용어에 맞춘다. 게임 코드·씬은 건드리지 않는다.

## 목표

1. `오그먼트` → `증강`으로 통일한다.
2. `무기 베이` 등 인게임에 없는 말을 쓰지 않고, HUD 표기 **무기 모듈**에 맞춘다.
3. 개요의 ‘줄타기·전장 거칠어짐’ 서사를 쌍방향 증강 선택 강조로 바꾼다.
4. 무기 설명 문장을 평이하게 다시 쓴다.
5. `project.godot` `config/features`를 `4.7`로 맞춘다 (문서·규칙과 동일).

## Acceptance Criteria

1. `docs/submission/03-game-guide.md`, `04-ai-usage.md`, `05-team-roles.md` 본문에 `오그먼트`가 없다 (변경 이력 인용 제외).
2. 제출 가이드 본문에 `무기 베이`/`무기고`가 없다.
3. 개요 핵심 재미 문장이 플레이어·적 증강 선택을 말한다.
4. `project.godot`의 `config/features`에 `"4.7"`이 있다.

## 범위 밖

- 인게임 UI 문자열·스펙(`docs/design/`) 전면 용어 통일
- `tools/run-godot.cmd` 기본 실행 파일 버전
