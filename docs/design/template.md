# <주제명>

## 목적·플레이 의도

플레이어가 경험할 재미와 이 기능의 역할.

## 확정 규칙

동작 시작·종료 조건, 순서, 대상, 예외와 다른 기능과의 상호작용.

## 수치·공식

단위, 기본값, 범위, 중첩·반올림 규칙. 같은 값을 다른 문서에 복제하지 않고 링크한다.

## 화면·입력

표시 정보, 키보드·마우스 조작, 포커스 복귀와 취소 동작.

## 구현 참고

관련 씬·스크립트·리소스 경로. 코드 내부 구조는 필요한 만큼만 기록한다.

## 완료 조건·검증

플레이어나 테스트가 관찰할 수 있는 결과와 확인 방법.

## 이번 변경

확정된 변경 범위와 구현 상태. 구현 완료 후 위 본문에 통합한다.

## 미결정

아직 합의하지 않은 아이디어·질문. 구현 대상으로 취급하지 않는다.
