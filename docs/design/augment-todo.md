## 실드 재생

현재 실드가 최대 미만이면 **한 칸씩** 회복한다. 시설로 최대치만 늘리는 것과 별개. **시작 실드 1** (`shield-base-one`).

### 규칙

1. **실드가 깎이는 즉시**(또는 현재 < 최대인 동안) 충전 게이지가 차기 시작한다. 별도 무피격 대기 없음.
2. 잔여 실드 게이지 **아래**에 작은 **충전 게이지**가 천천히 찬다 (충전 초는 `@export` / 데이터).
3. 충전 게이지가 꽉 차면 현재 실드 **+1** (최대 이하) · 게이지 리셋 후, 아직 최대 미만이면 바로 다음 칸 충전 재개.
4. 피격(실드 흡수·선체 피격 모두) 시 **충전 게이지만 리셋**하고, 실드가 여전히 최대 미만이면 **즉시 다시 차기 시작**.
5. **한 칸이 완전히 채워지기 전에는 그 충전분으로 방어되지 않음.** 이미 보유한 실드만 버퍼 HP. 피해는 실드 → 선체 순으로 깎인다 (전체 이벤트 차단 게이트 없음).
6. 현재 = 최대이면 충전 게이지는 0·숨김.

### UI

- `ShipStatusHud` 실드 바 아래 세컨더리 ProgressBar(또는 동등)로 충전률 0~1 표시.

### 메모

- `restore_shield(1)`를 충전 완료 시에 호출하는 경로가 자연스러움.
- 비상 전력망(동력로)은 실드 흡수 피격에도 발동 — 그 피격도 충전 게이지를 리셋한 뒤 즉시 재충전.

## 메모 규칙

- **플레이어** 후보는 가능하면 `facility_id`(무기실·동력로(현 격납고)·엔진·선체·레이더·실드)를 적어 둔다.
- **적** 후보는 스탯(`HEALTH` / `MOVE_SPEED` / `ACTION_RATE`)인지, behavior 컴포넌트인지 구분한다.
- 수치 초안이 있으면 메모에 (예: Hurtbox scale 0.85, 폭발 딜레이 0.4s).
- 구현 착수 시 이 표의 상태를 `ready` → feature slug를 메모에 남기고, 머지 후 `done` 처리.
