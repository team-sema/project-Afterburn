# Feature: 레이저 굴절빔 VFX

## 목적

`laser_refract`가 주 빔의 피격점에서 다른 적으로 피해를 전달하는 순간, 실제 판정 경로를 읽을 수 있는 짧은 보조 빔으로 표시한다.

## 규칙

1. 보조 빔은 기존 굴절 피해가 적용된 경우에만 주 피격점과 대상 Hurtbox 사이에 생성한다.
2. 대상 선택, 피해 틱, `fork_damage_mult`(기본 0.55)는 변경하지 않는다.
3. 밝은 코어와 넓고 옅은 글로우를 겹친 청록색 네온 선으로 표시한다.
4. 각 피해 틱에서 경로를 갱신하고, 기본 0.13초 동안 빠르게 페이드아웃한다.
5. 여러 굴절 경로는 한 VFX 노드가 짧은 세그먼트 목록으로 관리해 매 틱 노드 생성을 피한다.
6. 무기 종료·재설정 시 남은 세그먼트를 즉시 제거한다.

## AC

- [x] 굴절 피해가 발생한 주 피격점→보조 대상 경로가 표시된다.
- [x] 코어보다 글로우가 넓고 옅으며 두 레이어가 함께 감쇠한다.
- [x] 대상이 없거나 특성이 비활성이면 보조 빔이 표시되지 않는다.
- [x] 기존 굴절 피해 판정과 배율은 유지된다.
- [x] 전용 headless 스모크 테스트가 통과한다.
