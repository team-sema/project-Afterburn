# Feature: 궤도 방벽 적당 1회 피해

## 목적

궤도 방벽이 같은 적에게 `area_entered` 재진입으로 피해를 반복하지 않게 한다. 적 하나당 접촉 피해는 **딱 1회**.

## 규칙

1. 세그먼트 Hitbox의 기본 `area_entered` 피해를 막고, 방벽이 직접 처리한다.
2. 적 루트(또는 hurtbox)를 대상으로 기록하고, 이미 맞은 대상은 추가 `hurt`를 내지 않는다.
3. 탄막 흡수(세그먼트 Hurtbox) 동작은 그대로 둔다.
4. 장착 해제·재장착 시 기록은 비운다.

## AC

- [x] 같은 적에게 방벽 피해 1회만
- [x] 다른 적은 각각 1회씩 맞을 수 있음
