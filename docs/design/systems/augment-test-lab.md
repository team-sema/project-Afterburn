# 통합 증강 테스트 랩

## 목표

- `weapon_test/weapon_test_lab.tscn`을 시설·적 증강을 직접 검증하는 테스트 씬으로 확장한다.
- 실제 런의 무작위 3장 오퍼와 별개로, 테스트 대상 증강을 스크롤 목록에서 임의 선택해 즉시 적용한다.
- 테스트 랩 전용 편의 동작은 실제 Gameplay의 오퍼·진행 규칙을 바꾸지 않는다.

## 입력과 흐름

- `C`: 플레이어 레벨업 이벤트를 모의 발생시키고 PLAYER 증강 목록을 연다.
- `V`: 적 강화 이벤트를 모의 발생시키고 ENEMY 증강 목록을 연다.
- 목록은 증강 표시명·ID·설명을 보여 주며, 한 항목을 고르면 기존 레지스트리와 무기 로드아웃에 적용한 뒤 닫힌다.
- 목록 행은 원본 아이콘 크기와 무관하게 일정한 높이를 유지해 한 화면에서 여러 증강을 비교할 수 있어야 한다.
- `Esc` 또는 닫기 버튼으로 적용 없이 목록을 닫을 수 있다.

## 풀

- PLAYER: `res://resources/player_augments/` 아래의 시설 증강 12종. 무기 획득·레벨·특성은 기존 오른쪽 무기 UI가 담당하므로 제외한다.
- ENEMY: `res://resources/enemy_augments/` 아래의 모든 `EnemyAugment` `.tres`.
- Gameplay 풀 미등록 리소스도 테스트 대상에 포함한다.

## 테스트 편의 적용 규칙

- 시설 모듈: 빈 슬롯을 사용하고, 필요하면 슬롯을 확장하며, 최대 용량이 가득 찼으면 첫 슬롯을 교체한다.
- 적 증강: `EnemyAugmentRegistry`에 추가하며 `max_stacks` 한도는 유지한다.
- 기존 스폰 대상은 그대로 두고, 적 증강 효과는 이후 생성되는 적과 스폰 패턴에서 검증한다.

## 완료 조건

- `C`와 `V`가 각각 PLAYER/ENEMY 전체 스크롤 목록을 연다.
- 개별 증강 행이 과도하게 커지지 않고 스크롤 영역 안에서 조밀하게 표시된다.
- 플레이어 시설 증강 12종과 적 7종(풀 미등록 1종 포함)이 리소스에서 자동 발견된다.
- `C` 목록에는 무기 획득·레벨·특성 증강이 표시되지 않는다.
- 선택한 증강이 랩의 기존 `PlayerAugmentRegistry`, `EnemyAugmentRegistry`에 적용된다.
- 기존 적 스폰·지속 스폰·무기/특성 직접 제어가 계속 동작한다.
- 랩 스모크 테스트와 Godot 프로젝트 파싱 검사를 통과한다.
