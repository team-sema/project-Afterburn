# 플레이어 증강 티어 기반

## 목표

플레이어 증강에 `SILVER`·`GOLD`·`PRISMATIC` 설계 등급을 부여할 수 있는 데이터와 선택 카드 표현 기반을 만든다. 티어는 장기적으로 증강의 메커니즘 변화 폭과 희소성을 나타내지만, 이번 범위에서는 등장 정책이나 밸런스를 변경하지 않는다.

## 데이터 계약

- `PlayerAugment.Tier`: `SILVER`, `GOLD`, `PRISMATIC`
- `PlayerAugment.tier` 기본값: `SILVER`
- 기존 리소스는 필드 생략 시 모두 실버로 유지한다.
- 티어별 등장 시점·확률과 한 오퍼의 티어 결정은 `AugmentOfferController`의 후속 정책으로 둔다.
- 적 증강에는 이번 범위에서 티어를 추가하지 않는다.

## 카드 표현

- 모든 플레이어 증강 카드에 영문 티어 라벨과 상단 액센트를 표시한다.
- 실버: 청백색, 1px 프레임, 낮은 글로우
- 골드: 금색, 2px 프레임, 중간 글로우
- 프리즘: 보라색 3px 프레임, 높은 글로우, 스펙트럼 순환 라벨·액센트
- 색상만으로 구분하지 않도록 라벨과 프레임 굵기를 함께 사용한다.
- 적 증강 카드는 기존 표현을 유지하고 티어 라벨을 숨긴다.

## 비범위

- 티어 출현 확률과 Threat/레벨별 해금
- 한 오퍼에 동일 티어 3장을 보장하는 선택 정책
- 기존 증강의 골드·프리즘 재분류 및 수치 조정
- 골드·프리즘 전용 메커니즘 구현
- 적 증강 티어

## AC

1. 새 `PlayerAugment`는 명시하지 않으면 실버다.
2. 세 티어 카드가 라벨·프레임 색·프레임 굵기로 서로 구분된다.
3. 프리즘 카드의 상단 액센트가 시간에 따라 색을 바꾼다.
4. 적 증강 카드와 기존 선택·리롤 동작은 유지된다.
5. `docs/spec/augments.md`와 smoke test가 현재 구현 범위를 반영한다.
