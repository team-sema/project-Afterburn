# Feature: 무기 육각 모듈 아이콘

## 목적

STATUS 패널의 무장 표시가 **무기 이름 텍스트**에만 의존해 작은 육각 모듈에서 읽기 어렵고, 한글 이름이 잘렸다.
무기 정체성을 **벡터 아이콘**으로 옮기고, 텍스트는 **수치(레벨·잔탄)** 만 남긴다.

## 동작 규칙

1. `WeaponDefinition.icon`에 무기별 아이콘을 지정한다. 아이콘은 `assets/svg/weapons/weapon_<id>.svg` 흰색 마스크이고, 색은 HUD가 틴트한다
2. 육각 모듈은 위에서부터 **슬롯 제목 → 아이콘 → 수치** 3단으로 배치한다
   - 제목·수치가 비면 그 칸을 아이콘이 쓴다
   - 아이콘은 종횡비를 지켜 정사각형으로 들어가며, 네 꼭지점이 육각형 안에 남는 최대 크기로 맞춘다
3. 모듈별 표시
   | 모듈 | 제목 | 아이콘 | 수치 |
   |---|---|---|---|
   | 메인 | `메인` | 장착 주무기 | `Lv.N` (무기) |
   | 예비 | `예비` | 대기 주무기 | `Lv.N` (무기) |
   | 보조 1~3 | `AN LN` (위치·무기 레벨 축약) | 장착 보조무기 | 발사형은 `남은/최대`, 방벽은 없음 |
   | 보유 주무기 행 | 없음 | 보유 주무기 | `Lv.N` |
4. 빈 슬롯·잠김 슬롯은 아이콘 없이 기존 `—` / `잠김` 표시를 유지하고, 어둡게 처리한다
5. 어두운 모듈은 아이콘도 같이 어두워진다
6. 정의에 아이콘이 없으면 **이름 텍스트로 되돌린다** (데이터 누락이 화면에서 사라지지 않게)
7. 아이콘은 무기 종류를 실루엣만으로 구분한다 — 쌍발 볼트(블래스터) · 단일 빔(레이저) · 부채꼴(샷건) · 굵은 포탄(캐넌) · 원형 폭탄(플라즈마 폭탄) · 지느러미 미사일(유도탄) · 분절 링(방벽)
8. 보조 모듈은 `48×48`이며 잔탄은 기본 배치에서 9px 글자와 1px 외곽선을 사용한다

## Acceptance Criteria

- [x] 무기 정의 7종 모두 아이콘을 가진다
- [x] 메인·예비·보조·보유 모듈이 이름 대신 아이콘을 표시한다
- [x] 무기 Lv / 발사형 잔탄이 중복 없이 읽힌다
- [x] 아이콘이 육각형 외곽선을 넘지 않는다
- [x] 빈칸·잠김 모듈은 아이콘 없이 기존 표시를 유지한다
- [ ] 36px 보유 행에서도 무기 구분이 가능하다 (플레이 확인 필요)

## 구현 메모

- `HexModuleFrame.set_module_icon` / `_place_icon` — 육각형 기울기(`HEX_EDGE_SLOPE`)를 고려한 정사각형 배치
- `PlayerWeaponLoadout.get_weapon_icon` — 슬롯에 없는 **보유** 주무기의 아이콘 조회용
