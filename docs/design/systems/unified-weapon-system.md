# Feature: 통합 무기 시스템

## 목적

주무기/보조무기 구분을 없애고, 모든 무기를 동일 장착 베이에서 동시에 작동시키는 통합 슬롯으로 바꾼다. 성장은 `weapon_id`에 귀속되며 STATUS UI는 코어 육각+특성 위성+기록 영역으로 표현한다.

## 규칙

1. `WeaponDefinition.Category`를 쓰지 않는다. 모든 무기는 동일 슬롯 API를 쓴다.
2. 장착 수는 `@export max_equipped_weapon_count`(기본 3). 코드에 3을 하드코딩하지 않는다.
3. 장착된 무기는 각자 쿨다운으로 **동시에** 작동한다. 탄약·소진 삭제가 없다.
4. 레벨·특성은 `weapon_id`별 중앙 상태. 슬롯/UI는 소유하지 않는다.
5. 무기 획득·레벨업은 **증강 선택**으로 처리한다 (필드 드롭 없음 — `weapon-augment-acquisition`).
6. 기록 복원 시 레벨+1 하지 않는다. 레벨+1은 `WEAPON_LEVEL` 증강만.
7. Z 스왑·X 픽업 차단·MAIN/RESERVE/보조 탄약 UI 제거.
8. 무기실 = 전 장착 무기 피해 배율. 격납고 탄약 효과 제거·「효과 미정」.
9. 무기 전용 특성은 데이터/상태/UI 스캐폴드 + 증강 카드. 전투 효과·밸런스는 후속.
10. 기록 영역에서 직접 장착하지 않는다. 만석 신규 획득은 증강 안 교체 UI.
11. 공격 간격·기본 피해·탄속·범위·유도 성능 등 전투 수치는 각 `WeaponSystem` 루트가 소유한다. 투사체는 생성 전에 값을 주입받고 이동·충돌·연출만 담당한다.

## 무기 설정 위치

| 무기 | WeaponSystem 루트 설정 |
|---|---|
| 블래스터 | 공격 간격, 기본 피해, 탄속 |
| 샷건 | 공격 간격, 기본 피해, 펠릿 수, 확산각, 펠릿 속도 |
| 보조 캐넌 | 공격 간격, 기본 피해, 탄속 |
| 유도탄 | 공격 간격, 기본 피해, 탄속, 회전 속도, 재탐색 간격 |
| 플라즈마 폭탄 | 공격 간격, 기본 피해, 탄속, 신관 시간, 시각 폭발 반경, 피해 판정 마진 |
| 레이저 | 피해 틱 간격, 틱 피해, 빔 폭, 전개 시간 |
| 궤도 방벽 | 궤도 반경·속도, 피해, 세그먼트 체력·크기 |

튜닝은 `player_ship/weapons/*_weapon_system.tscn`의 루트 노드에서 한다. 투사체 씬의 충돌 shape와 VFX 수치는 투사체 표현/물리 구조에 해당하며 무기 밸런스 수치로 사용하지 않는다.
