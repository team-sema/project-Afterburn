# Feature: 통합 무기 시스템

## 목적

모든 무기를 동일 장착 베이에서 동시에 작동시키는 통합 슬롯으로 운영한다. 성장은 `weapon_id`에 귀속되며, 장착 중이 아닌 무기의 레벨·특성은 보존하지 않는다.

## 규칙

1. `WeaponDefinition.Category`를 쓰지 않는다. 모든 무기는 동일 슬롯 API를 쓴다.
2. 장착 수는 `@export max_equipped_weapon_count`(기본 3). 코드에 3을 하드코딩하지 않는다.
3. 장착된 무기는 각자 쿨다운으로 **동시에** 작동한다. 탄약·소진 삭제가 없다.
4. 레벨·특성은 `weapon_id`별 중앙 상태(`WeaponProgressState`). 슬롯/UI는 소유하지 않는다.
5. 무기 획득·레벨업·특성은 **증강 선택**으로 처리한다 (필드 드롭 없음).
6. `WEAPON_LEVEL`은 장착 중 무기의 레벨을 영구 +1한다 (가역 모듈 보너스 아님).
7. 교체·해제 시 해당 무기의 레벨·특성을 **완전 삭제**한다. 재획득은 Lv.1·특성 없음으로 시작한다.
8. Z 스왑·X 픽업 차단·MAIN/RESERVE/보조 탄약 UI를 쓰지 않는다.
9. 무기실 = 전 장착 무기 피해 배율. 격납고 탄약 효과는 없고 「효과 미정」.
10. 무기 전용 특성은 데이터/상태/UI 스캐폴드 + 증강 카드. 전투 효과·밸런스는 후속.
11. 만석 신규 획득은 증강 안 교체 UI만 사용한다.
12. 공격 간격·기본 피해·탄속·범위·유도 성능 등 전투 수치는 각 `WeaponSystem` 루트가 소유한다.

## STATUS UI

- 장착 베이: 동일 크기 헥스 가로 나열, 호버/클릭 포커스
- 하단: 선택된 무기 설명 + 장착 모듈(특성) 헥스
- 시설 칩·한 줄 상세는 `ShipPanel`이 담당한다

## 무기 설정 위치

| 무기 | WeaponSystem 루트 설정 |
|---|---|
| 블래스터 | 공격 간격, 기본 피해, 탄속 |
| 샷건 | 공격 간격, 기본 피해, 펠릿 수, 확산각, 펠릿 속도 |
| 보조 캐넌 | 공격 간격, 드론당 기본 피해, 탄속, 기본 드론 수·편대 간격 |
| 유도탄 | 공격 간격, 기본 피해, 탄속, 회전 속도, 재탐색 간격 |
| 플라즈마 폭탄 | 공격 간격, 기본 피해, 탄속, 신관 시간, 시각 폭발 반경, 피해 판정 마진 |
| 레이저 | 피해 틱 간격, 틱 피해, 빔 폭, 전개 시간 |
| 궤도 방벽 | 궤도 반경·속도, 피해, 세그먼트 크기 |

목록·획득 풀 정본: `docs/spec/player.md`, `docs/spec/augments.md`.
