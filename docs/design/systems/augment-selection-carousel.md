# Feature: 증강 선택 캐러셀 UI

## 목적

전장을 가리는 별도 증강 화면을 축소하고, 중앙의 3장 카드 캐러셀과 기존 우측 STATUS를 함께 사용해 선택 결과를 한 화면에서 읽게 한다.

## 규칙

1. 오퍼 중 전투는 계속 일시정지하지만 전장과 좌우 HUD는 불투명한 전체 화면으로 가리지 않는다.
2. 선택창 외곽 전체를 좌우 STATUS 사이의 중앙 플레이필드 경계 안에 넣고, 그 안에 최대 3장의 세로형 카드를 실린더 단면처럼 겹쳐 배치한다.
3. 포커스 카드는 전면·원본 크기·불투명으로 표시하고, 좌우 카드는 뒤쪽·축소·반투명으로 표시한다. 선택 중에는 별도 조작 설명 문구를 표시하지 않는다.
4. 좌우 입력은 캐러셀이 단독으로 처리한다. 카드 간 `focus_neighbor` 좌우 이동은 막고, 진행 중 회전·쿨다운 중 입력은 버리며 키를 뗀 뒤에는 추가 회전을 예약하지 않는다. 길게 누르면 키가 눌린 동안에만 `carousel_min_rotation_interval`(기본 0.45초)마다 한 칸씩 회전한다.
5. 포커스되지 않은 카드를 클릭하면 먼저 해당 카드로 회전하고, 포커스 카드를 누르거나 `ui_accept`를 입력하면 선택을 확정한다.
6. 리롤은 현재 포커스 카드 한 장만 교체한다. 다른 두 카드는 유지하고 포커스도 유지하며 런 리롤 횟수 1회를 소비한다. 표시는 `[R] 리롤 (남은 횟수)` 단일 버튼만 사용한다.
7. 플레이어 시설 카드 포커스는 우측 `ShipPanel`에서 같은 primary tag를 강조하고, 첫 빈 범용 슬롯에 들어올 시설 아이콘을 점멸한다. 빈 슬롯이 없으면 점멸을 생략한다.
8. `범용 슬롯 +1`은 포커스된 카드 Kind와 무관하게 플레이어 오퍼에 항상 표시한다(`스킵 후 범용 슬롯 확장 n → n+1`). 포커스·호버 시 우측 `ShipPanel`의 다음 슬롯 한 칸을 점멸한다. 용량이 최대(15)면 `스킵 (범용 슬롯 MAX 도달)`로 비활성 표시하고 선택·포커스 이동에서 건너뛴다.
9. 신규 무기 획득 카드 포커스는 우측 `WeaponLoadoutHud`의 첫 빈 베이에 후보 아이콘을 점멸한다. 베이가 가득 차 교체가 필요하면 점멸 미리보기를 생략한다. 이 경우에도 하단 `범용 슬롯 +1`을 병기 안내 문구로 바꾸거나 숨기지 않는다.
10. 무기 모듈 카드 포커스는 우측 STATUS에서 대상 무기 베이를 강조하고, 장착 모듈 영역의 해당 모듈 또는 첫 빈 모듈 칸에 다음 레벨 아이콘을 점멸한다.
11. 카드 포커스가 바뀌거나 오퍼가 닫히면 이전 STATUS 미리보기를 즉시 정리한다.
12. 리롤은 실제 `Button`이며 위·아래 입력으로 `카드 → 리롤 → 범용 슬롯 +1` 순서에 진입하고 다시 카드로 돌아갈 수 있다. 적 오퍼에서는 리롤과 범용 슬롯 확장을 표시하지 않는다.
13. 적 오퍼도 같은 캐러셀을 사용하지만 플레이어 STATUS 미리보기를 표시하지 않는다.
14. 만석 무기 교체와 가득 찬 시설 모듈 교체 오버레이의 확정·취소 흐름은 유지한다.

## 구현

- 오퍼·단일 리롤: `augment_offer_controller.gd`
- 카드 캐러셀: `menus/augment_selection_overlay.gd`, `menus/augment_selection_overlay.tscn`
- 우측 STATUS 연결: `world_shell.gd`, `menus/ship_panel.gd`, `menus/weapon_loadout_hud.gd`
- 현재 동작 정본: `docs/spec/augments.md`, `docs/spec/player.md`, `docs/spec/scene-flow.md`

## Acceptance Criteria

- [x] 중앙 카드 3장이 전면 1장·후면 2장의 실린더형 깊이로 보인다.
- [x] 선택창 외곽 전체가 중앙 플레이필드 경계 안에 들어온다.
- [x] 좌우 입력과 비포커스 카드 클릭으로 포커스가 순환하며 tween 전환된다.
- [x] 선택 확정은 현재 포커스 카드에만 적용된다.
- [x] 리롤은 현재 포커스 카드만 교체하고 다른 두 카드와 포커스를 유지한다.
- [x] 범용 슬롯 확장 점멸이 오퍼 내부 복제 패널이 아니라 우측 STATUS에서 보인다.
- [x] 시설 증강 포커스 시 첫 빈 범용 슬롯에 후보 아이콘이 점멸한다.
- [x] 빈 무기 베이가 있으면 신규 무기 후보가 해당 베이에서 점멸한다.
- [x] 무기 모듈 후보가 대상 무기의 장착 모듈 영역에서 다음 레벨 아이콘으로 점멸한다.
- [x] 무기 베이가 만석이면 신규 무기 점멸을 생략하고 기존 교체 흐름을 유지한다.
- [x] 무기 Kind 포커스여도 하단 슬롯 확장이 유지되며, 최대 용량이면 `스킵 (범용 슬롯 MAX 도달)`로 비활성 표시한다.
- [x] 오퍼 종료·중단·카드 Kind 전환 시 STATUS 미리보기 상태가 남지 않는다.
- [x] 플레이어와 적 오퍼가 모두 키보드·마우스로 선택 가능하다.
- [x] 위·아래 입력으로 카드·리롤 버튼·범용 슬롯 확장 사이를 이동한다.
- [x] 좌우 키를 길게 눌러도 tween이 중단되지 않고 캐러셀 전체가 회전한다.
- [x] 연속 회전 시작 간격이 최소 0.45초로 제한된다.
- [x] 키를 뗀 뒤에는 추가 회전을 예약하지 않는다.
- [x] 카드 간 좌우 focus_neighbor 자동 이동으로 쿨다운을 우회하지 않는다.
- [x] 관련 스모크 테스트와 프로젝트 parse가 통과한다.
