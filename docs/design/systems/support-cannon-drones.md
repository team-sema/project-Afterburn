# 보조 캐넌 옵션 드론

## 목적

최근접 적을 조준하던 공전 포드를 전통적인 종스크롤 슈팅의 옵션/부가 드론으로 개편한다. 유도탄과 역할을 분리하고, 플레이어 전방 화력을 좌우 편대로 보조하는 무기로 정의한다.

## 동작

1. 무기 장착 시 플레이어 좌우에 드론 2기를 배치한다.
2. 드론은 충돌·HP가 없는 무기 비주얼이며 부모 변환을 상속하지 않는 전역 위치에서 이동한다.
3. 각 드론의 목표점은 매 프레임 `플레이어 위치 + 좌우 편대 오프셋`으로 계산한다.
4. 드론은 기본 100px/s로 이동하고, **드론에서 플레이어 본체 중심까지의 거리**에 15% 보정률을 곱한 속도를 더한다. 거리 보너스는 최대 50px/s다.
5. 플레이어가 횡이동하면 반대편 드론은 본체와 멀어져 빨라지고, 이동 방향 쪽 드론은 본체와 가까워져 상대적으로 느려진다.
6. 이동 방향은 각 드론의 좌우 편대 목표점을 향하므로, 속도 차이로 간격이 역동적으로 변한 뒤 원래 편대로 복귀한다.
7. 편대는 좌우 대칭 오프셋을 유지하려 한다. 공전하거나 적을 추적하지 않는다.
8. 공격 주기마다 모든 드론이 각자의 총구에서 화면 전방(`Vector2.UP`)으로 동시에 발사한다.
9. 적이 없어도 발사 방향은 변하지 않는다.
10. 무기 해제·교체 시 드론도 WeaponSystem과 함께 제거된다.

## 편대 증설 모듈

- 기존 저장·리소스 호환을 위해 trait ID `aux_heavy_barrel`은 유지한다.
- 표시명과 역할은 `편대 증설 프레임`으로 변경한다.
- 장착 시 드론 수 `+2`(총 4기), 드론당 피해 `×0.7`.
- 추가 드론도 좌우 한 쌍으로 배치해 대칭을 유지한다.
- 자동 급탄·고폭 탄두·고속 철갑 특성은 기존 효과를 유지한다.

## 전투 수치

| 항목 | 값 |
|---|---:|
| 기본 드론 수 | 2 |
| 증설 드론 수 | +2 |
| 발사 간격 | 0.8초 |
| 드론당 피해 | 9 |
| 탄속 | 190 |
| 드론 추종 속도 | 100px/s |
| 본체 거리 속도 보정 | 드론↔플레이어 중심 거리 ×15% · 최대 +50px/s |

피해·연사·탄속에는 시설 배율과 보조 캐넌 모듈 Lv.I~III 파라미터가 동일하게 적용된다.

- [x] 플레이어 중심에서 멀어진 드론일수록 상한 안에서 더 빠르게 편대 목표점으로 이동한다.
- [x] 모든 보조탄은 적 위치와 무관하게 전방으로 이동한다.
- [x] 편대 증설 프레임 적용 시 좌우 대칭 드론 4기로 갱신된다.
- [x] 고폭·관통·탄속·연사 특성이 계속 적용된다.
- [x] 무기 교체 시 드론과 타이머가 정리된다.
- [x] 관련 headless 스모크 테스트가 통과한다.
