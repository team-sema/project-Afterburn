# Feature: 실드 재생 · 충전 UI

## 목표

실드가 최대 미만이면 소형 충전 게이지가 차고, 꽉 차면 현재 실드 +1. 피격 시 게이지만 리셋 후 즉시 재충전.

## 규칙

1. 현재 < 최대이면 **즉시** 충전 시작 (무피격 대기 없음).
2. `regen_charge_duration`초마다 게이지 1.0 → `restore_shield(1)` → 게이지 0 (기본 **30초**). 아직 미만이면 연속 충전.
3. 피격(실드 흡수·선체) → `notify_hit()`으로 게이지 0, 미만이면 바로 재충전.
4. 충전 중 칸은 방어력 없음. 이미 보유한 실드 칸만 버퍼 HP로 피해를 흡수하고, 초과분은 선체로 넘긴다.
5. 최대일 때 게이지 0·숨김.

## UI

- `ShipStatusHud` 실드 바 아래 `%ShieldChargeBar` (얇은 ProgressBar, 0~1).
