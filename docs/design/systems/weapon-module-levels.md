# Feature: 무기 모듈 레벨 개편

## 목적

무기 코어의 범용 Lv.1~3 성장을 없애고, 각 무기 특성 모듈을 반복 선택해 Lv.I~III으로 성장시키는 구조로 전환한다. 모든 무기에 공통으로 적용되는 피해·공격 속도 증가는 무기실 시설 모듈이 담당한다.

## 규칙

1. 무기는 획득 시 고정된 기본 성능으로 시작하며 자체 `level`을 보유하지 않는다.
2. `WEAPON_LEVEL` Kind·카드·오퍼·배율 API를 제거한다.
3. 모든 `WEAPON_TRAIT` 모듈은 Lv.I~III을 가지며 동일 카드를 다시 선택하면 1레벨 상승한다.
4. Lv.I은 기존 `params`, Lv.II·III은 `rank_overrides`의 명시적 값으로 동작한다. 자동 수치 추론은 하지 않는다.
5. Lv.III 모듈 카드는 오퍼 후보에서 제외하고, 로드아웃 API도 최대 레벨을 넘기지 않는다.
6. STATUS와 증강 미리보기는 무기 자체 레벨을 표시하지 않고 모듈의 현재→다음 레벨을 표시한다.
7. 새 무기는 모듈 없이 장착된다. 교체·해제 시 피교체 무기의 모든 모듈 레벨을 삭제한다.
8. 범용 피해 증가는 무기실 `WEAPON_DAMAGE_MULT`, 범용 공격 속도 증가는 `WEAPON_FIRE_RATE_MULT` 시설 모듈로 제공한다.
9. 무기 고유 모듈은 형태·행동·조건부 화력을 성장시키며, 무기 자체의 범용 피해/공속 레벨을 대체하지 않는다.
10. 진행 상태는 런 한정이므로 기존 런 저장 마이그레이션은 제공하지 않는다.

## 모듈 수치 정책

- 기존 모듈 효과를 Lv.I 기준으로 유지한다.
- Lv.II·III은 모듈의 핵심 장점을 강화한다.
- 발사 수·세그먼트 수가 늘어나는 모듈은 개별 피해 페널티를 함께 조정해 폭증을 제한한다.
- 범용 피해·공속만 올리는 신규 무기 특성은 만들지 않는다.

- [x] 28개 무기 모듈 모두 Lv.I~III 전투 파라미터를 가진다.
