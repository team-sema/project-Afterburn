# Feature: 무기 교체 삭제 · 증강 리롤

## 목적

장착 무기 교체 시 성장 상태를 완전히 삭제하고, 무기 기록/복원을 제거한다. 증강 선택에 런 제한 리롤을 추가한다. STATUS는 최신 함선 UI를 유지하며 기록 영역만 제거한다.

## 규칙

1. 필드 무기 드롭은 계속 비활성. XP `drop_chance`는 데이터 유지(추가 밸런스 확정 금지).
2. 통합 베이·동시 작동·탄약 없음 유지. `max_equipped_weapon_count` 설정값.
3. **기록/복원 없음.** 교체·언장착으로 빠진 무기의 level/traits/`_progress` 항목을 삭제한다.
4. 같은 무기를 다시 `WEAPON_ACQUIRE`하면 기본 레벨·특성 없음으로 시작.
5. `WEAPON_LEVEL` / `WEAPON_TRAIT`는 **장착 중** 무기만.
6. 만석 신규 획득 → 증강 안 교체 UI. 확정 전에 장착/삭제하지 않음. 확정 시 피교체 성장 삭제.
7. 리롤: `@export max_reroll_count`(임시 기본 2), `remaining_reroll_count` 런 상태. 선택 전만. XP/레벨 불변. 직전 세트와 완전 동일 회피(가능 시 1회 재추첨).
8. 격납고 신효과·슬롯 증가·유형별 확률·특성 전투 로직 임의 추가 금지.
9. STATUS: 베이 코어+특성+상세만. RecordsScroll 제거. ShipPanel 유지.
