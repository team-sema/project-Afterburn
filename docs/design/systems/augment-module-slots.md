# Feature: 증강 모듈 슬롯

## 목적

플레이어 증강을 영구 누적 보너스가 아니라 함선 부위 슬롯에 장착하는 모듈로 통일한다. 오퍼마다 새 모듈을 설치하거나 부위의 수용량을 늘리는 선택을 제공한다.

## 규칙

1. 모든 실제 플레이어 오퍼 리소스는 하나의 `facility_id`를 가지며 슬롯 하나를 차지한다.
2. 무기실·격납고·엔진·선체·레이더·실드는 각각 빈 슬롯 1개로 시작한다.
3. 각 부위의 슬롯 용량은 오퍼를 소비해 1개씩 늘릴 수 있고 최대 3개다.
4. 빈 슬롯이 있으면 선택한 모듈을 첫 빈 슬롯에 설치한다.
5. 부위가 가득 찼으면 교체 모달에서 기존 모듈 하나를 고른다. 취소하면 오퍼 선택으로 돌아간다.
6. 교체된 모듈의 스탯·시설 효과·무기 레벨 보너스는 즉시 제거된다.
7. 동일 모듈의 중복 설치와 효과 중첩을 허용한다.
8. 주·보조 무기 강화 모듈은 설치 시 대상 무기 ID를 저장하고 장착 중에만 유효 레벨 +1을 제공한다.
9. 적 증강 오퍼는 기존 3지선다와 누적 레지스트리를 유지한다.

## 대상 부위

| 부위 | 현재 모듈 |
|---|---|
| 무기실 | 연사속도, 무기 공격력, 주무기 강화, 집속 조준기 |
| 격납고 | 보조무기 강화, 탄약 적재대 |
| 엔진 | 이동속도, 추력 편향기 |
| 선체 | 반응 장갑 |
| 레이더 | 광역 탐지기 |
| 실드 | 실드 축전기 |

## 오퍼 UI

```text
증강 1    증강 2    증강 3
--------------------------------
함선 부위와 현재 모듈 슬롯
```

- 카드 포커스·호버는 대상 부위의 칩과 배선을 하이라이트한다.
- 전투 화면과 오퍼의 슬롯은 숫자 카운터가 아니라 최대 3개의 `18×18px` 둥근 사각 프레임으로 표시한다.
- 설치된 모듈은 해당 슬롯 안에 `PlayerAugment.icon`을 표시하고, 아이콘이 없으면 임시 점 표시를 사용한다.
- 확장 옵션에 포커스하거나 마우스를 올리면 현재 용량 다음 슬롯이 점멸한다.
- 함선 부위 클릭 또는 `ui_accept`는 확장 가능한 경우에만 슬롯 확장 선택으로 처리한다.
- 카드 행과 2열×3행 함선 부위 사이를 방향키로 왕복할 수 있고, Tab 순환에서도 모든 유효 선택지에 도달한다.
- 전투 화면의 함선 패널은 같은 슬롯 정보를 읽기 전용으로 표시한다.

## Acceptance Criteria

- [x] 모든 플레이어 오퍼 증강에 유효한 대상 부위가 있다.
- [x] 모든 부위가 빈 슬롯 1개로 시작하고 최대 3개까지 확장된다.
- [x] 오퍼가 상단 증강 3개와 하단 함선 UI를 표시한다.
- [x] 카드 포커스·호버가 대상 부위를 하이라이트한다.
- [x] 숫자 카운터 대신 둥근 슬롯 프레임과 설치 모듈 아이콘을 표시한다.
- [x] 확장 옵션의 다음 슬롯이 게임 일시정지 중에도 점멸한다.
- [x] 모든 카드와 확장 가능한 함선 부위를 방향키·Tab·`ui_accept`로 조작할 수 있다.
- [x] 빈 슬롯 설치와 가득 찬 슬롯 교체·취소가 동작한다.

- [x] 플레이어가 모듈 대신 부위 슬롯을 확장할 수 있다.
- [x] 적 증강 오퍼 동작은 유지된다.
