# Feature: 증강 모듈 슬롯

## 목적

플레이어 **시설 효과** 증강을 범용 슬롯에 장착한다. 기존 함선 부위 구분은 module tag와 아이콘으로 유지한다. 무기 획득·전용 모듈은 시설 슬롯을 쓰지 않는다. 상세 전환 규칙은 [unified-module-slots](unified-module-slots.md)가 정본이다.

## 규칙

1. `FACILITY_EFFECT` 오퍼만 module tag를 가지며 범용 슬롯 하나를 차지한다.
2. 동일 전투 스탯을 `STAT_MULTIPLIER` 등으로 **이중 적용하지 않는다.** (플레이어 오퍼 풀에 스탯 모듈 없음)
3. `WEAPON_ACQUIRE` / `WEAPON_TRAIT`는 시설 슬롯을 소모하지 않는다. 모듈 레벨은 `PlayerWeaponLoadout`에 런 동안 반영된다.
4. 범용 슬롯은 5개로 시작한다.
5. 범용 슬롯 용량은 오퍼를 소비해 1개씩 늘릴 수 있고 최대 15개다.
6. 빈 슬롯이 있으면 선택한 모듈을 첫 빈 슬롯에 설치한다.
7. 범용 풀이 가득 찼으면 교체 모달에서 tag와 무관하게 기존 모듈 하나를 고른다. 취소하면 오퍼 선택으로 돌아간다.
8. 교체된 모듈의 시설 효과는 즉시 제거된다.
9. 동일 모듈의 중복 설치와 효과 중첩을 허용한다 (시설 `module_count_values` 곡선).
10. 적 증강 오퍼는 슬롯 없이 누적 레지스트리를 유지한다.

## 대상 부위

| 부위 | 효과 모듈 |
|---|---|
| 무기실 | 집속 조준기 (공통 공격력) |
| 격납고 | 격납고 확장 (효과 미정) |
| 엔진 | 추력 편향기 (이동속도) |
| 선체 | 반응 장갑 |
| 레이더 | 광역 탐지기 |
| 실드 | 실드 축전기 |

## 오퍼 UI

```text
       [포커스 카드]
 [후면 카드]   [후면 카드]       | 우측 STATUS
          범용 슬롯 +1           | 범용 모듈 슬롯
```

- 중앙 카드는 실린더형 캐러셀로 겹쳐 표시하고 좌우 입력으로 포커스를 순환한다.
- 카드 포커스·호버는 **우측 STATUS**에서 같은 primary tag가 장착된 범용 슬롯 외곽선을 하이라이트하고 첫 빈 범용 슬롯에 후보 시설 아이콘을 점멸한다. 범용 슬롯이 가득 찼으면 후보 점멸은 생략한다. 무기 전용 카드는 시설 tag 하이라이트를 강제하지 않는다.
- 6개 시설 칩은 표시하지 않고, tag는 5×3 범용 육각 슬롯의 임시 아이콘과 데이터로 유지한다.
- 단일 `범용 슬롯 +1` 버튼은 무기 Kind 포커스를 포함해 플레이어 오퍼에 항상 두고, 포커스·호버하면 우측 STATUS의 다음 육각 칸이 점멸하며 선택 시 용량을 확장한다. 최대 용량이면 비활성으로 건너뛴다.
- `ShipPanel`은 전투 중 읽기 전용이며 오퍼 중에도 선택 결과를 적용하지 않는 미리보기만 표시한다.
