# Feature: 증강 모듈 슬롯

## 목적

플레이어 **시설 효과** 증강을 함선 부위 슬롯에 장착한다. 부위별 효과는 시설 정의가 담당한다. 무기 획득·전용 모듈은 시설 슬롯을 쓰지 않는다.

## 규칙

1. `FACILITY_EFFECT` 오퍼만 `facility_id`를 가지며 해당 부위 슬롯 하나를 차지한다.
2. 동일 전투 스탯을 `STAT_MULTIPLIER` 등으로 **이중 적용하지 않는다.** (플레이어 오퍼 풀에 스탯 모듈 없음)
3. `WEAPON_ACQUIRE` / `WEAPON_TRAIT`는 시설 슬롯을 소모하지 않는다. 모듈 레벨은 `PlayerWeaponLoadout`에 런 동안 반영된다.
4. 무기실·격납고·엔진·선체·레이더·실드는 각각 빈 슬롯 1개로 시작한다.
5. 각 부위의 슬롯 용량은 오퍼를 소비해 1개씩 늘릴 수 있고 최대 3개다.
6. 빈 슬롯이 있으면 선택한 모듈을 첫 빈 슬롯에 설치한다.
7. 부위가 가득 찼으면 교체 모달에서 기존 모듈 하나를 고른다. 취소하면 오퍼 선택으로 돌아간다.
8. 교체된 모듈의 시설 효과는 즉시 제거된다.
9. 동일 모듈의 중복 설치와 효과 중첩을 허용한다 (시설 `module_count_values` 곡선).
10. 적 증강 오퍼는 슬롯 없이 누적 레지스트리를 유지한다.

## 대상 부위

| 부위 | 효과 모듈 |
|---|---|
| 무기실 | 집속 조준기 (공통 공격력) |
| 격납고 | 격납고 확장 (효과 미정) |
| 엔진 | 추력 편향기 (이동속도) |
| 선체 | 반응 장갑 |
| 레이더 | 광역 탐지기 |
| 실드 | 실드 축전기 |

## 오퍼 UI

```text
증강 1    증강 2    증강 3
--------------------------------
함선 부위와 현재 모듈 슬롯
```

- 카드 포커스·호버는 대상 부위의 칩과 배선을 하이라이트한다. 무기 전용 카드는 시설 하이라이트를 강제하지 않는다.
- 슬롯은 최대 3개의 둥근 사각 프레임으로 표시하고, 설치 모듈은 `PlayerAugment.icon`을 넣는다.
- 확장 옵션에 포커스·호버하면 다음 슬롯이 점멸한다.
- 전투 중 `ShipPanel`은 읽기 전용이다.
