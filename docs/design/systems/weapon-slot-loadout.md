# Feature: 무기 획득 및 강화 (슬롯 무장)

## 목적

플레이어는 **주무기 1 + 보조무기 최대 3**을 장착한다. 무기는 **몬스터 드롭 아이템**으로만 획득하고, 오그먼트는 무기 지급 없이 **성능·운용**만 강화한다.

## 동작 규칙

1. 시작: 주무기 블래스터 Lv.1, 보조 슬롯 3개 전부·빈칸
2. 적 처치 시 확률로 무기 아이템 드롭
3. 주무기 드롭
   - 장착 중과 **동일** → 해당 주무기 슬롯 강화 (최대 Lv.3)
   - **다른** 주무기 → 교체 확인 후 장착 (레벨 1로 리셋). 거부 시 아이템 유지
4. 보조무기 드롭
   - 장착 중과 **동일** → 해당 보조 슬롯 강화
   - 빈 슬롯 있음 → 자동 장착
   - 슬롯 가득 참 → 교체할 슬롯 선택 (취소 시 아이템 유지)
5. 오그먼트 풀에는 무기 장착·슬롯 해금 카드 없음 (스탯·슬롯 오버클럭 등 성능만)

## Acceptance Criteria

- [ ] 오그먼트 선택에 무기 장착/해금 카드가 나오지 않는다
- [ ] 적 처치 시 무기 픽업이 드롭될 수 있다
- [ ] 동일 무기 픽업 시 해당 슬롯 레벨이 오른다 (최대 3에서 미소비·아이템 유지)
- [ ] 다른 주무기 픽업 시 교체/유지 선택 가능
- [ ] 보조 빈 슬롯에 자동 장착, 가득 차면 교체 UI
- [ ] HUD에 주/보조 슬롯·레벨·한글 무기명이 표시된다

## 구현 메모

- 획득 단일 진입점: `WeaponAcquisitionController`
- 장착/강화: `PlayerWeaponLoadout`
- 드롭: `WeaponDropComponent` + `WeaponDropTable`
