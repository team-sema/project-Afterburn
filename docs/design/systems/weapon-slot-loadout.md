# Feature: 무기 획득 및 강화 (슬롯 무장)

## 목적

플레이어는 **주무기 1 + 보조무기 최대 3**을 장착한다. 주무기는 드롭으로 **무기 레벨**을 쌓고, 보조무기는 **소모품**(사용량)이다. **슬롯 강화는 오그먼트**로만 올린다.

## 동작 규칙

1. 시작: 주무기 블래스터(무기 Lv.1), 보조 슬롯 3개 해금·빈칸, 슬롯 Lv.1
2. 적 처치 시 확률로 무기 아이템 드롭
3. **주무기** 필드 픽업 → 그 무기 ID 레벨 (최대 3). 슬롯 레벨과 별개
4. 주무기 픽업
   - 이미 장착 중 → 무기 레벨만 상승
   - 다른 주무기 → 무기 레벨 반영 후 교체 확인. 거부해도 레벨은 유지(스왑 시 복원)
5. **보조무기** 픽업 (소모품, **자체 레벨 없음**)
   - 이미 장착 중 → **사용량 리필**
   - 빈 슬롯 → 장착 / 가득 참 → 교체 UI
   - 사용량 소진 시 슬롯에서 제거
6. 주무기 스왑 시 **슬롯 레벨은 유지**, **무기 레벨은 무기별로 보존**
7. 보조 성능 배율 = 플레이어 공통 × **슬롯만** (무기 Lv 없음)
8. 오그먼트: 스탯 + **주/보조 슬롯 오버클럭**만 (무기 지급 없음)
9. 궤도 방벽: 조각 파괴 = 영구 소모(월드에서 사라짐). 전량 파괴 시 슬롯 비움. HUD에 N/M 표시 없음. 동일 픽업으로 리필
10. 발사형 보조: 정해진 탄약 소모 후 슬롯 제거. HUD에 남은 탄약 표시
11. 보조 유도탄: 근접 적 추적. 드롭 테이블 포함

## Acceptance Criteria

- [ ] 오그먼트에 슬롯 오버클럭이 나오며, 필드 픽업으로 슬롯 레벨이 오르지 않는다
- [ ] 동일 주무기 픽업 시 무기 레벨이 오른다
- [ ] 동일 보조무기 픽업 시 사용량이 리필된다
- [ ] 보조 소진 시 슬롯이 비고, HUD에 슬롯 Lv / 사용량이 구분 표시된다

## 구현 메모

- `PlayerWeaponLoadout._weapon_levels` — 주무기에만 사용
- `WeaponSystem.refill_consumable` / `depleted` — 보조 소모품
- 슬롯 강화: `upgrade_main_slot` / `upgrade_auxiliary_slot` (오그먼트만)
