# Feature: 무기 획득 및 강화 (슬롯 무장)

## 목적

플레이어는 **주무기 1 + 보조무기 최대 3**을 장착한다. 주·보조 모두 무기 ID별 **무기 레벨** 하나만 사용하고, 보조무기는 별도로 사용량을 가진 소모품이다. 슬롯은 장착 위치와 해금 상태만 보유한다.

## 동작 규칙

1. 시작: 주무기 블래스터가 **메인(발사)** 슬롯에서 무기 Lv.1, 예비 빈칸, 보조 슬롯 3개 해금·빈칸
2. 적 처치 시 확률로 무기 아이템 드롭
3. **주무기** 필드 픽업 → 그 무기 ID 레벨 (최대 3). 이미 메인/예비에 있으면 레벨만. 새 무기면 **예비 교체**
   - **X**: 새 주무기 차단 토글. ON이면 메인/예비에 없는 주무기는 픽업하지 않음 (드롭 유지)
4. **Z** 키: 메인 ↔ 예비 스왑 (예비 비면 무시). 각 무기 레벨 유지
5. **보조무기** 픽업 (소모품 + 무기별 Lv.1~3)
   - 이미 장착 중 → **사용량 리필**
   - 빈 슬롯 → 장착 / 가득 참 → 교체 UI
   - 사용량 소진 시 슬롯에서 제거
6. 무기 강화 모듈: 설치 시 **현재 주무기/선택한 보조무기 ID**를 기록하고, 장착 중 해당 무기의 유효 레벨 +1 (무기 지급 없음)
7. 모든 무기의 로컬 배율은 무기 레벨 하나에서 계산한다: Lv.2 공격력 ×1.2, Lv.3 공격속도도 ×1.2
8. 궤도 방벽: 조각 파괴 = 영구 소모(월드에서 사라짐). 전량 파괴 시 슬롯 비움. HUD에 N/M 표시 없음. 동일 픽업으로 리필
9. 발사형 보조: 정해진 탄약 소모 후 슬롯 제거. HUD에 남은 탄약 표시
10. 보조 유도탄: 근접 적 추적. 드롭 테이블 포함

## Acceptance Criteria

- [x] 슬롯 레벨 없이 주·보조 강화 모듈이 장착 중 대상 무기의 유효 레벨을 올린다
- [x] 동일 주무기 픽업 시 무기 레벨이 오른다
- [x] 동일 보조무기 픽업 시 사용량이 리필된다
- [x] 보조 소진 시 슬롯이 비고, 재획득 시 기존 무기 레벨이 유지된다

## 구현 메모

- `PlayerWeaponLoadout._weapon_levels` — 모든 주·보조무기의 유일한 성장 상태
- `WeaponSystem.refill_consumable` / `depleted` — 보조 소모품
- 기본 레벨: `PlayerWeaponLoadout._weapon_levels`
- 장착 모듈 보너스: `PlayerWeaponLoadout._augment_weapon_level_bonuses`
