# Feature: 무기 STATUS 포커스 디테일

## 목적

STATUS 장착 베이에서 장착 중 무기를 포커스하면, 해당 무기의 헥스 코어를 강조하고 하단에 선택 무기·장착 모듈 디테일을 표시한다.

## 규칙

1. 기존 `WeaponCoreCluster` / `HexModuleFrame` / `WeaponLoadoutHud`를 재사용. STATUS 전체 재작성 금지.
2. **호버 또는 클릭**으로 포커스한 장착 무기에 하단 디테일을 바인딩한다 (ShipPanel 시설 호버와 동일). 포커스 전환 시 베이 행 전체를 재빌드하지 않고 스타일만 갱신한다.
3. 장착 베이 헥스: 아이콘 + Lv만. 이름·특성 목록은 디테일 패널.
4. 디테일: `선택된 무기`(48px 육각 아이콘·이름) + `장착된 모듈`(28px 육각 아이콘·단계) + **설명만**. 전투 수치는 STATUS에 표시하지 않는다 (`docs/spec/player.md` 정본).
5. `무기 모듈` 장착 베이는 48px flat-top 육각형, `장착된 모듈`은 28px flat-top 육각형을 사용한다. 각 행은 열마다 반 칸 세로로 어긋나고 모든 육각형이 변을 공유하는 벌집으로 배치한다. 빈 베이·빈 모듈은 빈 윤곽, 비포커스는 디밍.
6. 시설 강화·전투 특성 효과·슬롯 수 변경은 하지 않는다.
