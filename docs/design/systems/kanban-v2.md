# 백로그 칸반 (v2)

> **운영 보드:** [아이템 칸반](https://app.notion.com/p/102c71bf78394bcaa9ff627548faf7f9?v=3c9b8c11155f8111bfeb000c00cae3b8) (`team-sema` · 주간 회의록과 형제)  
> **규칙:** `.cursor/rules/kanban-tickets.mdc`

티켓·열·태그는 **Notion만** 정본이다. 카드 **생성·열 이동·완료 처리**는 사람이 한다.  
에이전트는 `/feature`·`/push`·`/merge-feature`에서 **제목·본문 초안만 추천**한다 (Notion에 쓰지 않음).

## 열 (4)

백로그 → 구현 중 → 검증 → 완료

| 열 | 언제 |
|----|------|
| 백로그 | 아직 안 하는 것 (아이디어·스펙 미완·구현 직전 포함) |
| 구현 중 | 지금 코딩 중 (인당 1~2장) |
| 검증 | `main`에 들어간 직후 · 수정이 필요해도 일단 여기 (코멘트로 구분) |
| 완료 | 사람이 플레이/검증 확인한 뒤만 |

- merge 후 사람이 **`검증`** 으로 옮김 (에이전트가 열을 바꾸지 않음)

## 카드 = feature slug

`feature/player-augment-behaviors` → Notion `카드 ID` `player-augment-behaviors` (사람이 생성 시 설정)

## 팀 반영 경로

| 경로 | 언제 |
|------|------|
| 사람이 Notion에서 카드·열·태그 관리 | **기본** |
| `/push`·`/merge-feature` | **제목·본문 초안 추천**만 |
| 사용자 **「노션에 반영해줘」** 명시 | MCP로 Notion 페이지·`상태` 수정 |

## Pages (문서 사이트)

Settings → Pages → branch `main` / folder `/docs`  
스펙: `/spec/` · 홈: `/` · **칸반 UI 없음** (Notion 링크만)
