# 플레이어

## 기획 의도

여러 무기를 동시에 운용하고, 함선·무기 모듈 선택으로 한 판의 빌드를 만든다. 피격은 코어(선체)와 실드로 읽힌다.

## 한 줄 루프

XP 오브 수집 → 요구량 충족 시 `AUGMENT READY [C]` → **C**로 오퍼 → 시설/무기/특성 선택 → 빌드 강화.

상세 트리거·오퍼 UI는 [오그먼트](augments.md). 카드 목록·수치는 [함선 모듈](ship-modules/index.md) · [무기 모듈](weapon-modules/index.md).

## 조작

| 입력 | 동작 |
|------|------|
| WASD / 화살 | 이동 |
| 발사 | 장착 무기 자동 사격 |
| **C** | XP 준비 시 플레이어 오그먼트 |
| **ESC** | 수동 일시정지 |

본 게임의 기체 이동은 [조종석 전장 경계](scene-flow.md#조종석-hud--시각-기준)에 제한한다. 측면 및 아래 경사 UI 영역에는 들어가지 않으며, 출격 입력 잠금 중에는 화면 밖 상승 연출을 허용한다.

## 장착 슬롯

| 슬롯 | 규칙 | 정본 |
|------|------|------|
| 무기 베이 3 (프리즘 제4 베이로 4) | 시작 블래스터 · 동시 사격 · 만석 시 교체(피교체 모듈 삭제) | [무기 모듈](weapon-modules/index.md) · [오그먼트](augments.md#규칙-카드-ship_rule) |
| 범용 시설 5→15 | `FACILITY_EFFECT`만 · 카드 대신 슬롯 확장 선택 시 +1 칸 · tag는 시너지용 | [함선 모듈](ship-modules/index.md) |

## 생존

- 피격 판정은 `PlayerHitPoint`의 원(기본 반경 3px) 하나다. 화면의 피격점 표시는 바깥 가장자리가 판정 반경과 정확히 같은 하드 엣지 원(반경 안쪽 1px 어두운 테두리 · 붉은 채움 · 밝은 중심점)으로 그려 판정 영역을 그대로 보여 주며, 판정 밖으로는 아무것도 그리지 않는다. 글로우 두 겹은 배경 연출이고 중심 표시는 글로우·블러 없이 그려, 함선이 소수점 좌표로 움직여도 피격점이 흔들려 보이지 않게 한다. 반경을 바꾸면 표시와 판정이 함께 바뀌고 테두리는 항상 1px를 유지한다. 선체 시설 **압축 코어**는 반경을 1px 줄이며(`HIT_POINT_RADIUS_ADD` 합산), 시설로 줄여도 반경은 **2px 아래로 내려가지 않는다**. 적탄 반경은 그대로라 실제 피격 거리는 두 반경의 합이다.
- 피격 피해는 이벤트당 **항상 1** · 실드가 먼저 흡수
- 기본 선체 HP 1 · 실드 최대 2(시작) · 피격 후 0.6초 무적. 선체는 1을 넘지 않으며 전투 HUD에는 실드만 표시한다. 시작 실드 2는 견딜만한 피격과 위험한 피격을 한 런에서 모두 겪게 하려는 값이며, 피격 연출 체감 뒤 밸런스와 함께 다시 본다.
- 실드는 최대 미만이면 즉시 충전 경과를 세며 기본 30초마다 1칸 회복한다. 경과가 필요 초에 도달하면 실드 +1하고 경과를 0으로 돌린다. HUD 소형 게이지는 경과/필요 초다. 모든 피격은 경과를 초기화하며, 충전 중인 칸은 피해를 막지 않는다. 최대치면 충전 게이지를 숨긴다.
- XP 수집 반경 기본 36px · 레이더 모듈이 반경·획득량 배율

### 피격 연출

의도: 맞은 순간 "아직 괜찮다"와 "다음은 죽는다"를 1초 안에 구분하게 한다. 견딜만한 피격은 실드가 막아 줬다는 짧은 확인이고, 위험한 피격은 플레이를 바꾸라는 경고다. 함선·전장·조종석이 같은 등급을 같은 순간에 말하며 글자는 쓰지 않는다. 실드 상실 자체는 조종석 표시등과 이벤트 로그가 알리고, 이 절은 전장 안(함선·피격점·전장 가장자리)과 조종석 패널·실드 게이지의 반응을 정한다.

등급은 피격 **후** 실드로 정한다.

| 등급 | 조건 | 뜻 |
|------|------|-----|
| 견딜만한 피격 `ABSORBED` | 실드가 흡수했고 피격 후 실드 ≥ 1 | 한 번 더 버틴다 |
| 위험한 피격 `SHIELD_BROKEN` | 실드가 흡수했고 피격 후 실드 0 | 다음 피격은 사망 |
| 치명 피격 `LETHAL` | 실드 0에서 맞아 선체 피해 | 기존 파괴·게임 오버. 추가 연출 없음 |

- 신호: `HurtComponent`가 흡수 처리 직후 `player_hit(severity, hit_position, impact_direction)`을 낸다. `impact_direction`은 피격점 중심에서 적 Hitbox 중심을 뺀 방향(탄이 온 쪽의 반대)이며, 위치를 모르면 위쪽이다. 무적 중에는 피격이 없으므로 신호도 없다. 최대 실드가 2 이상이면 `ABSORBED`가 여러 번 난 뒤 `SHIELD_BROKEN`이 한 번 난다. 실드가 한 번에 2 이상 깎이는 경우는 없다(피해는 항상 1).
- 공통 연출(두 등급): 함선 코어 스프라이트와 타이트 글로우만 화이트 플래시(`FlashComponent`; 넓은 글로우까지 칠하면 함선 아래 흰 덩어리가 생겨 제외), `ImpactVfx` 공용 렌더러의 섬광·스파크·링(프로필 `effects/impact_profiles/player_shield.tres`, 실드색 청색 (0.28, 0.7, 0.94) 글로우·백색 코어, 스파크 속도 120~220px/s·퍼짐 ±70°·수명 0.25초), 조종석 패널 흔들림. 전장과 함선 위치는 흔들지 않는다. 흔들림은 조종석 여섯 패널이 각자 다른 무게로 울리며 규칙은 [조종석 HUD · 패널 흔들림](scene-flow.md#조종석-표시등-제어)에 둔다. 모두 게임 시간이라 일시정지에 멈춘다. 기존 0.6초 무적 반투명은 그대로다. 함선 쪽 연출은 `PlayerHitFeedback` 컴포넌트가 `player_hit` 신호를 받아 낸다.
- 등급별 수치:

| 항목 | 견딜만한 피격 | 위험한 피격 |
|------|--------------|------------|
| 플래시 | 0.12초 | 0.22초 |
| 섬광·스파크 강도 | 1.0 (섬광 반지름 5 · 스파크 6) | 1.6 (섬광 8 · 스파크 10) |
| 실드 파열 링 | 반지름 14px · 0.3초 | 반지름 24px · 0.3초 |
| 조종석 패널 흔들림 | 기본 진폭 ×1.0 | 기본 진폭 ×1.8 + 표시등 전력 딥 0.06초 |
| 전장 가장자리 경고 | 없음 | 아래 |
| 피격점 맥동 | 없음 | 아래 |
| 실드 게이지 | 꺼지는 칸 흰색 섬광 | 전체 붉은 섬광 ([조종석 HUD](scene-flow.md#조종석-표시등-제어)) |
| 전투 이벤트 로그 | 없음 (기존 규칙 유지) | 기존 `SHIELD LOST` |

- 위험한 피격 전용 · 전장 가장자리 경고: 전장이 실제로 렌더링하는 영역(논리 340px 레인이 아니라 좌우 bleed까지 포함한 전체) 테두리 안쪽 36px를 붉은색 (0.95, 0.2, 0.22)으로 바깥이 진한 그라데이션으로 덮는다. 레인 경계에서 멈추면 프레임 안쪽에 사각형이 떠 보이므로 바깥 경계는 항상 프레임 아트 뒤에 숨긴다. 피격 순간 알파 0.3으로 켜져 0.5초 동안 0.1까지 내려가고, 실드가 0인 동안 조종석 표시등과 같은 0.8초 주기로 알파 0.04↔0.1을 맥동한다. 배경 위·적탄 아래에 그려 탄 판독을 가리지 않는다. 실드가 0에서 양수로 돌아오면 0.3초 동안 사라진다. 런 시작 실드 0(최대 0)은 섬광 없이 맥동만 시작한다.
- 위험한 피격 전용 · 피격점 맥동: 실드가 0인 동안 피격점 붉은 채움의 밝기를 같은 0.8초 주기로 1.0↔1.6 맥동한다. 반경·테두리·중심점 크기는 바꾸지 않아 판정 표시 규칙을 지킨다. 회복 시 즉시 1.0으로 돌아간다.
- 시간 정지·탄 감속은 두지 않는다. 그 역할은 프리즘 규칙 카드 `BrinkRule`이 맡으며 기본 연출과 겹치지 않는다.
- 효과음: 현재 피격음이 없다. 견딜만한 피격은 짧고 높은 타격음, 위험한 피격은 낮고 긴 파열음을 두는 방향이나 에셋이 없어 **미결정**이다. 이 초안은 효과음 구현을 승인하지 않는다.
- 적용 범위: 함선 연출은 `ship.tscn` 안에 있어 본 게임·`gameplay.tscn`·Lab 모두에서 난다. 전장 가장자리 경고는 `gameplay_world` 월드의 가시 영역 기준이라 Lab의 직사각형 전장에서도 같은 두께로 그린다.

## Ship 요약

그룹 `"player"`. 자식: Move / WeaponMount / Augment·Facility Applier / Shield / ExperienceCollector / PlayerHitPoint / Hurt …

구현 세부(컴포넌트·HUD 레이아웃)는 코드·관련 테스트가 정본이며, 이 페이지는 플레이 규칙을 요약한다.

## 완료 조건·검증

- 시작 블래스터 · 빈 베이 획득 · 만석 교체가 위 규칙대로 동작한다.
- 시설·무기 모듈 수치는 각 모듈 문서와 일치한다.
- 피격점 표시 원의 바깥 반경이 판정 반경과 같고 테두리는 그 안쪽에 있으며, 중심 표시는 글로우 재질 없이 글로우 위에 그려진다.

- 압축 코어 설치 시 판정·표시 반경이 1px 줄고, 제거하면 돌아오며, 겹쳐도 2px 아래로 내려가지 않는다.
- 피격 연출: 실드 2에서 맞으면 `ABSORBED` 신호와 함께 플래시·스파크·14px 링·패널 흔들림이 나고 전장 가장자리 경고·피격점 맥동은 없다. 실드 1에서 맞으면 `SHIELD_BROKEN` 신호와 강한 수치가 나며 가장자리 경고가 켜져 맥동하고 피격점이 맥동한다. 실드 0에서 맞으면 `LETHAL` 신호만 나고 기존 파괴로 이어진다. 회복하면 경고·맥동이 풀린다. 무적 중에는 신호·연출이 없고 일시정지에 모든 연출이 멈춘다. 기존 표시등·이벤트 로그 회귀가 유지된다.

검증 참고: `tests/weapon_replace_delete_reroll_test.gd` · `tests/player_hit_point_visual_test.gd` · `tests/hit_point_radius_facility_test.gd` · 피격 연출은 `tests/player_hit_feedback_test.gd`(등급 신호·플래시·임팩트·가장자리 경고·피격점 맥동·패널 흔들림·게이지 섬광·일시정지·회복·치명)와 게임 시간 0.1배 창 모드 캡처로 두 등급을 나란히 확인했다.
