# Elite Caster

## 외형

![Elite Caster](../enemies/sprites/enemy_elite_caster.svg)

- 원형의 고리·중앙 마름모를 계승한 **공중 탄막 발생기**. 작은 세로형 크리스탈을 중심에 두고, 상하가 열린 각진 고리 두 조각을 몸체와 떨어뜨려 배치한다. 코어는 고리 중앙에 맞춰 고리 안에 떠 있는 비율로 표현한다.
- 기존 Elite Fighter / Elite Awl의 흰색 마스크·날카로운 투명 절개를 공유한다. 색상은 엘리트 공용 적색/분홍 글로우와 연분홍 흰색 코어를 기준으로 한다.
- 크리스탈 내부의 마름모 절개와 하단의 가는 틈으로 결정의 면을 표현한다. 고리와 코어 사이에는 넓은 빈 공간을 남긴다.
- 에셋: `assets/enemies/enemy_elite_caster.svg` (128×160). 표시 배율 0.25 × 1.35에서 약 43×54px.
- 미리보기: `artifacts/elite_caster_design.png`, 재생성: `tools/run-godot.cmd --script res://artifacts/preview_elite_caster.gd`.

## 의도

일반 [Caster](../enemies/caster.md)의 "탄막 장판으로 비어 있는 통로를 찾게 한다"를 엘리트 관문 규모로 키운 **탄막 술사**.
세 가지 주문을 정해진 순서로 돌린다. 주문마다 빈 공간이 생기는 방식이 달라, 플레이어는 같은 "통로 찾기"를 매번 다른 모양으로 읽어야 한다. 탄이 멈추고, 휘고, 색이 바뀌는 변화가 곧 예고다.

## 플레이어가 고민할 점

- 호흡 링: 멈춰 쌓인 여러 겹의 링에서 휘어진 통로를 미리 찾아 두기
- 꽃잎 격자: 반대로 휘는 두 색의 탄이 만드는 마름모 빈칸으로 옮겨 타기
- 정지 조준: 바늘이 멈춰 붉게 변하는 순간 크게 옆으로 빠지기
- 주문 사이 휴식에 상단 본체로 화력을 넣기

## 하지 않는 것

- 빈틈 없이 화면을 메우는 탄막 (모든 주문에 빠져나갈 공간이 있다)
- 예고 없이 꺾이는 탄 (꺾이기 전 직진·정지·색 변화를 먼저 보인다)
- 돌진·자폭형 근접 압박 (Elite Awl / Elite Bomb 몫)

### 주문 순환

- 진입 중에는 사격하지 않는다. 표류 시작 후 0.6초 준비 → **호흡 링 → 꽃잎 격자 → 정지 조준** 순서로 반복한다.
- 각 주문의 마지막 발사 후 **1.4초** 휴식하고 다음 주문을 시작한다. 체력에 따른 패턴 변화는 없다.
- 각 주문을 시작할 때 플레이어 방향을 기준 방향으로 고정한다(표적이 없으면 아래).
- 수명은 모든 탄 8초. 일시정지 중 모든 단계가 정지한다. 처치 시 미래 발사는 멈추고 이미 발사된 탄은 탄소거 보상 대상이 된다.

### 1. 호흡 링 (분홍 원탄)

- 링 **5회**, 0.45초 간격. 각 링은 원탄 **20발**을 기준 방향 반대편 중심으로 320° 부채꼴에 펼쳐 기준 방향 쪽 **40°**를 비운다.
- 통로는 링마다 **9°**씩 회전한다. 회전 방향은 순환마다 시계/반시계를 번갈아 바꾼다(첫 순환 시계 방향).
- 탄은 150px/s로 나가 0.6초 동안 25px/s까지 감속(EASE_OUT)한 뒤, 링마다 다른 시간만큼 머물러 **다섯 링이 같은 순간에** 95px/s로 다시 가속(0.8초, EASE_IN)한다. 머무는 시간은 마지막 링 0.5초, 앞선 링일수록 0.45초씩 길다.
- 결과: 여러 겹으로 쌓인 링이 한꺼번에 퍼지고, 겹마다 9°씩 어긋난 빈틈이 휘어진 통로가 된다.

### 2. 꽃잎 격자 (분홍·보라 원탄)

- **4회**, 0.7초 간격. 매회 분홍 링 12발과 보라 링 12발을 함께 쏜다. 속도 75px/s, 링 기준각은 기준 방향에서 매회 13°씩 회전한다.
- 두 링 모두 0.3초 직진 후 1.4초 동안 각각 +100° / −100° 휜다(EASE_IN_OUT). 교차한 궤적이 마름모 빈칸을 만든다.

### 3. 정지 조준 (흰 바늘탄 → 적색)

- 바늘 링 **2회**, 1.0초 간격. 링당 **16발**, 두 번째 링은 11.25° 어긋난다.
- 바늘은 140px/s로 나가 0.7초 동안 정지(EASE_OUT)하고 즉시 **적색**으로 바뀐 뒤 0.35초 머문다. 이어서 0.25초 동안 플레이어를 향해 선회(초당 최대 1440°)하고 0.5초 동안 190px/s까지 가속(EASE_IN)한다.
- 적색 전환과 정지가 조준 예고다. 선회는 발사 후 0.95~1.2초 구간에만 일어나고 이후 직진한다.

### 증강 적용

- ACTION_RATE: 주문 안의 발사 간격에 배속으로 적용하되 최대 1.5배까지만 빨라진다. 휴식은 최소 0.8초. 탄의 감속·정지·선회 시간(예고)은 바꾸지 않는다.
- 탄 수 증강: 정지 조준의 링당 바늘 수에만 추가한다. 호흡 링·꽃잎 격자의 발수와 통로 폭은 바꾸지 않는다(일반 Caster와 같은 원칙).
- MOVE_SPEED: 표류 속도에 적용한다.
