# Elite Fighter

## 외형

![Elite Fighter](../enemies/sprites/enemy_elite_fighter.svg)

일반 적보다 훨씬 큰 **다익·포격기**. 중앙 용골에 좌우 날개·측면 포대가 붙은 형태로, Threat 관문임을 실루엣만으로 구분한다. **진한 적색/분홍** 글로우.
- 스프라이트: `assets/enemies/enemy_elite_fighter.svg`
- 틴트: 크림슨 글로우 · 밝은 코어 (`elite_fighter.tscn`). 피격 시 확대·폭발 스케일이 일반보다 큼.

## 의도

**Threat 관문**.
시퀀스의 ELITE 스텝에서 일반 웨이브와 결이 다른 “보스 아닌 중간 보스”로 리듬을 끊는다. 잡기 전에는 Threat·적 강화 선택이 열리지 않아, **처치가 다음 구간으로 가는 열쇠**가 된다.

## 플레이어가 고민할 점

- 일반 잡몹과 다른 집중 교전
- 관문 중에는 웨이브보다 엘리트를 우선하기
- 처치 후 적 오그먼트 선택으로, 다음 구간의 규칙이 바뀌는 걸 체감하기

## 하지 않는 것

- 일반 Encounter 풀에 섞인 “조금 센 잡몹”
- 보스를 대신하는 존재 (보스는 별도 BOSS 관문 — [보스](../bosses/index.md))
- 처치 없이 Threat만 올려 주는 타이머 보상

## 편대·Encounter에서의 역할

MainEncounterPool과 분리된 전용 스폰. 언제 뜨는지·게이트 규칙은 런·페이싱 문서를 본다.


## 확정 규칙·수치


MainEncounterPool과 **분리**된 시퀀스 관문 적. 일반 Encounter 후보가 아니다.

첫 관문(Threat 2)에 고정 출현하고, Threat 4부터는 [엘리트 로테이션](index.md#공통-규칙) 후보로 출현한다.

| 항목 | 값 |
|------|-----|
| Encounter | `threat_elite_single` |
| HP | Threat 2에서 **420**, 이후 Threat마다 **+140** (+ 적 `HEALTH` 증강 배율) |
| 점수 | 40 |
| XP | 확정 드롭 · 최소 탄소거 XP 10 ([런 페이싱](../run-pacing.md)) |
| 비주얼 | `enemy_elite_fighter.svg`, 넓은 어깨·쌍발 전방 포드·투명 절단면, 1.35배 · 강화 적색 글로우 |

## 전투

- 피격 연출: Anchor 기본 크기 대비 최대 1.2배, 총 0.24초(확대 0.024초·복귀 0.216초). 충돌 크기는 유지한다.
- 파괴 연출: `effects/elite_explosion_effect.tscn`, 일반 폭발의 2.5배(링 최대 반경 약 27px). 기존 재생 시간·처치 보상 흐름을 유지한다.

- 글로우: `effects/elite_glow.gdshader`. Tight/Wide는 Core와 같은 0.25 스케일에서 각각 텍스처 기준 7/22px 블러, 24px 쿼드 확장. 버텍스 틴트를 별도로 전달해 투명 영역으로도 빛이 퍼진다. Diffuse는 부드러운 방사형 감쇠를 사용한다.

- 이동: 상단 y=72 진입(56px/s) → 좌우 순찰(62px/s). 화면 밖 자동 despawn 정지
- 진입 중 사격 없음. 순찰 시작 후 0.45초 준비 → **A. 유도 포화·레일 포격 → 휴식 → B. 가위 포격 → 휴식** 순서로 반복한다. 휴식은 순찰하며 1.6초. 체력에 따른 패턴 변경은 없다.
- A-1. 유도 포화: 순찰하며 좌우 포대(기체 중심 ±14px, 아래 6px)에서 흰 바늘탄을 바깥 위쪽으로 4회 쏜다(0.34초 간격). 포대마다 3발, 아래 기준 ±115° 중심 40° 부채꼴(왼쪽 포대는 왼쪽 위, 오른쪽 포대는 오른쪽 위), 탄속 110. 바늘은 0.45초 동안 40px/s까지 감속(EASE_OUT)한 뒤 **적색**으로 바뀌며 0.9초 동안 플레이어를 추적(초당 최대 160°)하면서 175px/s로 가속하고, 이후 직진한다. 불꽃놀이처럼 위로 퍼졌다가 플레이어 쪽으로 꺾여 내려오므로, 적색 전환을 보고 늦게 옆으로 빠진다. 수명 6초.
- A-2. 레일 포격: 마지막 포화 직후 정지 → 당시 플레이어 방향을 고정하고 1초간 붉은 사선 예고 → 고정 방향으로 10회 연사(0.13초 간격, 탄속 195). 매회 흰 중앙 바늘 1발과 분홍 측면 바늘 2발(±30°에서 출발해 0.25초 동안 고정 방향으로 되돌아옴)을 쏴, 약 12px 간격의 **평행한 레일 3줄**이 된다 → 순찰 재개.
- B. 가위 포격: 시작 시 플레이어 방향을 기준으로 고정하고 순찰을 유지한 채 좌우 포대(기체 중심 ±14px, 아래 6px)에서 쌀탄 3방향(14도)을 동시에 10회 쏜다(0.16초 간격, 탄속 125). 왼쪽 포대는 기준 +40°, 오른쪽 포대는 기준 −40°로 바깥을 향해 쏘고, 탄은 0.2초 직진 후 1.0초 동안 안쪽으로 80° 휜다(EASE_IN_OUT). 두 줄기가 기체 아래에서 X자로 교차하므로 교차점 바깥 또는 줄기 사이로 피한다. 쌀탄 색은 주황(1.0, 0.55, 0.25)으로 A의 바늘탄과 구분한다. 유도 포화와 같은 포대를 쓴다.
- 공격 제어자는 이동·예고·고정 방향을 소유하고, 유도 포화/레일 포격/가위 포격은 각각 유한 BarrageSequence(`patterns/elite_fighter_pattern.gd`)로 실행한다. 마지막 발사 직후 `finished`로 단계 전환한다. 유도 포화의 추적은 공통 표적 조회(`resolve_target`)를 쓴다. 초기 준비와 예고·회복 시간은 Sequence 밖에서 유지한다.
- ACTION_RATE는 발사 간격과 휴식에 적용하되 유도 포화 최소 0.18초, 레일 최소 0.08초, 가위 포격 최소 0.1초, 휴식 최소 1초. 예고 1초와 탄의 감속·추적·선회 시간은 유지. 탄 수 증가 증강은 유도 포화·가위 포격의 포대별 발수에 추가 적용하고, 레일 3줄은 바꾸지 않는다.
- 체력바: 최초 피격 시 기체 위에 표시. 연속 피격마다 표시 시간을 갱신하고 마지막 피격 1.5초 후 페이드아웃

## 게이트

- 처치 즉시(게임은 멈추지 않음) 화면 안 적탄을 1 XP로 변환(밖은 소거, 변환이 10개 미만이면 모자란 만큼 처치 위치에서 추가) → 기존 XP와 함께 전량 강제 흡수 → Threat 상승 → 적 증강 오퍼 순서로 진행한다.
- XP 흡수 중에는 플레이어 오그먼트 `C` 입력을 받지 않는다.
- 타이머·Threat 상승·적 증강 오퍼 규칙은 [런·페이싱](../run-pacing.md) 정본.

## 완료 조건·검증

- 기획에 명시된 등장 조건, 공격 예고·실행·종료와 보상 처리를 확인한다.
- 관련 씬의 수치와 위 규칙을 대조하고, 행동 변경 시 해당 적의 스모크 테스트를 실행한다.
- `tests/elite_attack_smoke_test.gd`: 유도 포화의 포대 위치·바깥 위 발사·감속·적색 전환·추적, 예고·고정 방향 레일 3줄의 평행 수렴, A→B→A 순환과 휴식, 가위 포격의 포대 위치·발수·바깥 발사각·안쪽 선회, ACTION_RATE 최솟값, 탄 수 증강.
